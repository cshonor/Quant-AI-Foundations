# 第 3 章 · 所以你是说，这有机会！（概率论）

## 本章讲什么

概率的两种来源、随机变量与概率分布、六个常用分布（含 Python 实操），以及用蒙特卡洛模拟解决解析公式难算的问题。

## 要点

### 概率的两种来源

| 来源 | 思路 |
| :--- | :--- |
| **频率派** | 基于重复实验的长期频率 |
| **主观概率** | 结合经验、信念（可以通过**下注**来量化主观信念） |

二者都有价值，**不能迷信"数据一定优于主观经验"**。

### 随机变量与概率分布

- 分布为每一个可能结果分配概率，**全部结果概率总和等于 1**；
- 分为**离散分布**（PMF 概率质量函数）与**连续分布**（PDF 概率密度函数）；
- **重要区分**：连续分布**单点没有概率**（单点概率为 0），需要计算**区间下的面积**，依靠**累积分布函数 CDF** 做区间面积计算。

### 六大分布速查

| 分布 | 类型 | 用途 | 例子 |
| :--- | :--- | :--- | :--- |
| **伯努利** | 离散 | 单次二分类试验（成功/失败） | 进水 MacBook 能否恢复 |
| **通用离散分布** | 离散 | 有限多分类结果 | 游戏手柄不同颜色销量概率 |
| **二项分布** | 离散 | n 次独立重复伯努利试验，求 k 次成功概率 | 10 次防水测试出现 7 次成功 |
| **Beta 分布** | 连续 | 已知成功失败次数，**反推真实成功率**的可能性 | 10 次测试 7 次成功，评估真实成功率 |
| **泊松分布** | 离散 | 固定时间/区间内事件发生 k 次的概率 | 每分钟视频播放次数 |
| **指数分布** | 连续 | 泊松过程中**事件之间的间隔时长** | 两次视频观看的间隔时间 |

### 蒙特卡洛模拟

利用随机分布**复现现实场景**，得到解析公式难以直接算出的结论。本章用**咖啡店新咖啡师制作浓缩咖啡**演示，结合泊松、指数分布做仿真，可以模拟事件发生的时间线。

## 代码示例

```python
import numpy as np
from scipy import stats

# 二项分布：10 次防水测试出现 7 次成功（单次成功率 0.7）
print(stats.binom.pmf(7, n=10, p=0.7))    # PMF：恰好 7 次的概率
print(stats.binom.cdf(7, n=10, p=0.7))    # CDF：不超过 7 次的概率

# Beta 分布：10 次测试 7 次成功，反推真实成功率
# 后验 = Beta(alpha = 成功数 + 1, beta = 失败数 + 1)（均匀先验下）
posterior = stats.beta(a=8, b=4)
print(posterior.mean())                   # 成功率的均值估计
print(posterior.interval(0.90))           # 90% 置信区间

# 泊松：每分钟平均 3 次事件
lam = 3.0
print(stats.poisson.pmf(2, lam))          # 一分钟内恰好 2 次的概率

# 指数分布（事件间隔），均值 = 1/lam
dist = stats.expon(scale=1/lam)
print(dist.mean(), dist.interval(0.90))   # 平均间隔与 90% 区间

# 蒙特卡洛：模拟一小时（60 分钟）的事件时间线
gaps = dist.rvs(size=200, random_state=42)   # 事件间隔样本
timeline = np.cumsum(gaps)
print(timeline[timeline <= 60].size)         # 一小时内发生的事件数
```
