# §4.3 大数定律（弱大数定律）

以下结论均在 **n → ∞** 时成立，且为**依概率收敛**；公式用 **HTML 上下标**（见仓库根目录 [`书写约定-上下标与公式.md`](../../书写约定-上下标与公式.md)）。

对常数 c 与随机序列 Z<sub>n</sub>，「对任意小正数 ε，P(|Z<sub>n</sub> − c| &lt; ε) → 1」与「P(|Z<sub>n</sub> − c| ≥ ε) → 0」等价。

---

## 1. 伯努利大数定律（Bernoulli）

### 条件
n 次**独立重复**伯努利试验；事件 A 每次概率为 p；n<sub>A</sub> 为 n 次中 A 发生次数。

### 结论
频率 f<sub>n</sub> = n<sub>A</sub> / n **依概率收敛**到 p：

n<sub>A</sub> / n **依概率收敛于** p（n → ∞）。

等价：对任意小正数 ε，

**lim**<sub>n→∞</sub> P(| n<sub>A</sub>/n − p | &lt; ε) = 1。

### 意义
**频率稳定性**；用频率估计概率的理论依据之一。

---

## 2. 切比雪夫大数定律（Chebyshev）

### 条件
X<sub>1</sub>, X<sub>2</sub>, … **两两不相关**；E(X<sub>k</sub>) = μ<sub>k</sub>，D(X<sub>k</sub>) = σ<sub>k</sub><sup>2</sup>，且存在常数 C 使 **σ<sub>k</sub><sup>2</sup> ≤ C**（方差一致有上界）。

### 结论

(1/n)(X<sub>1</sub>+⋯+X<sub>n</sub>) − (1/n)(μ<sub>1</sub>+⋯+μ<sub>n</sub>) **依概率收敛于** 0。

等价：对任意小正数 ε，

**lim**<sub>n→∞</sub> P( |(1/n)(X<sub>1</sub>+⋯+X<sub>n</sub>) − (1/n)(μ<sub>1</sub>+⋯+μ<sub>n</sub>)| &lt; ε ) = 1。

### 特例
若 μ<sub>k</sub> ≡ μ，则

(1/n)(X<sub>1</sub>+⋯+X<sub>n</sub>) **依概率收敛于** μ。

### 注
伯努利大数定律为特例：X<sub>k</sub> 为第 k 次 A 的 0-1 指示变量，则 X<sub>1</sub>+⋯+X<sub>n</sub> = n<sub>A</sub>，E(X<sub>k</sub>) = p，D(X<sub>k</sub>) = p(1−p) 有界。

---

## 3. 辛钦大数定律（Khinchin）

### 条件
X<sub>1</sub>, X<sub>2</sub>, … **i.i.d.**；E(X<sub>k</sub>) = μ **存在**（**不要求**方差存在）。

### 结论

(1/n)(X<sub>1</sub>+⋯+X<sub>n</sub>) **依概率收敛于** μ。

### 特点
条件常用、较宽（仅 i.i.d. + 一阶矩）。

---

## 三大定律对比表

| 定律 | 独立性 | 同分布 | 矩条件 | 核心结论 |
| :--- | :--- | :--- | :--- | :--- |
| **伯努利** | 独立 | 0-1 结构 | p(1−p) 有限 | **n<sub>A</sub>/n** 依概率 **→ p** |
| **切比雪夫** | 两两不相关 | 不要求 | σ<sub>k</sub><sup>2</sup> 一致有界 | **样本均值 − 各期望平均** 依概率 **→ 0** |
| **辛钦** | 独立 | 同分布 | 期望存在 | **样本均值** 依概率 **→ μ** |

---

## 易错点速记

1. **弱大数** = **依概率**到常数；勿与**强大数**（几乎处处）混淆。  
2. **切比雪夫**：不相关 + 方差公共上界。  
3. **辛钦**：i.i.d. + 期望即可，**可无方差**。  
4. 三条均为 **n → ∞** 渐近；有限 n 用切比雪夫**不等式**是另一层面。
