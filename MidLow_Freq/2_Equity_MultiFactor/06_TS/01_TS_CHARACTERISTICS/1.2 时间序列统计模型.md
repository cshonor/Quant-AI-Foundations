# 1.2 时间序列统计模型

## 一、模型的核心思想
时间序列统计模型的本质：用数学解析式刻画观测数据背后的数据生成过程（DGP）。

通用表达：
x<sub>t</sub> = f(I<sub>t-1</sub>, w<sub>t</sub>)

- I<sub>t-1</sub>：t 时刻之前的历史信息（价格、成交量、波动率、滞后项等）
- w<sub>t</sub>：当期随机噪声（新息、冲击）

建模拆解逻辑：
x<sub>t</sub> = 信号<sub>t</sub> + 噪声<sub>t</sub>

- 信号项：趋势、周期、季节性、自相关、滞后传导（可建模、可预测）
- 噪声项：纯随机扰动、无规律部分（不可预测）

量化本质：尽可能剥离噪声、提取可交易信号，用于预测、择时、对冲和风控。

## 二、基础模型形式示例
### 1) 白噪声模型（White Noise）
   x<sub>t</sub> = w<sub>t</sub>

严格定义三条：
- E(w<sub>t</sub>)=0
- Var(w<sub>t</sub>)=σ<sup>2</sup>（常数）
- 任意非零滞后下自相关为 0（无记忆）

核心特点：
- 没有趋势、没有周期、没有自相关
- 完全随机，没有可交易信息

金融场景：
- 作为模型残差“是否合格”的基准
- 一个模型拟合后若残差接近白噪声，说明可解释信息提取较充分

### 2) 随机游走模型（Random Walk）
   x<sub>t</sub> = x<sub>t-1</sub> + w<sub>t</sub>

含义：今天价格 = 昨天价格 + 随机新息。

关键性质：
- 无固定均值，方差随时间扩散
- 典型非平稳序列
- 长期难以精准点预测

金融场景：
- 弱有效市场下价格行为的经典基准
- 常用于解释“方向难预测、但波动结构可建模”的现象

### 3) 一阶自回归模型 AR(1)
   x<sub>t</sub> = φ · x<sub>t-1</sub> + w<sub>t</sub>

参数理解：
- φ 是自回归系数，通常要求 −1 < φ < 1（平稳条件）
- 当前值由上一期线性驱动，再叠加当期噪声

系数直觉：
- φ 接近 1：强记忆、强惯性
- φ 接近 0：接近白噪声
- φ 的正负：决定更偏动量延续还是均值回归

模型地位：
- AR(p)、ARMA、ARIMA 等模型的基础原子结构

### 4) p阶自回归模型 AR(p)
AR(p) 是 AR(1) 的高阶扩展，允许当前值同时受前 p 期观测值影响：

x<sub>t</sub> = c + φ<sub>1</sub>*x<sub>t-1</sub> + φ<sub>2</sub>*x<sub>t-2</sub> + ... + φ<sub>p</sub>*x<sub>t-p</sub> + w<sub>t</sub>

- φ<sub>1</sub>,...,φ<sub>p</sub>：各滞后阶的影响系数
- p：模型记忆阶数（可由 AIC/BIC 或 PACF 辅助识别）
- w<sub>t</sub>：白噪声冲击项

直观理解：
- AR(1) 只看“昨天”；
- AR(p) 会同时看“最近 p 期”，能刻画更复杂的惯性与回归结构。

常见用途：
1. 对短中期价格惯性、利差、基差、波动率序列做线性动态拟合；
2. 作为 ARMA、ARIMA、VAR 等模型的前置基础模块；
3. 在回测中用于构建“多滞后预测因子”。

## 三、在量化交易中的意义
1. 所有量化策略都隐含某种时序模型假设：
   - 趋势策略依赖正自相关结构
   - 均值回归策略依赖负相关或稳定回归结构
   - 波动率交易依赖条件异方差结构

2. 对冲与调仓频率也受时序特征影响：
   - 序列记忆弱可降低调仓频率
   - 波动聚集强需要更高频动态风控

3. 回测有效性本质上取决于模型是否匹配真实 DGP：
   - 脱离时序结构的信号容易过拟合
   - 贴合 DGP 的信号更可能跨行情稳定

## 四、进阶模型谱系（承上启下）
在上述基础模型上，形成常用量化时序工具链：
- AR(p)：多阶自回归
- MA(q)：移动平均噪声结构
- ARMA(p,q)：AR + MA 混合
- ARIMA：加入差分处理非平稳序列
- GARCH 族：建模时变方差与波动聚集
- VAR：多变量联动建模

## 五、本节一句话总结
白噪声是“无信息基准”，随机游走是“价格基准”，AR(1)是“记忆基准”；后续预测、择时、波动率建模与对冲框架都由此展开。

## 六、MA模型与ARMA模型（和AR对照理解）

### 1) MA模型：看“过去冲击”
MA = Moving Average（移动平均模型）。

以 MA(1) 为例：
x<sub>t</sub> = w<sub>t</sub> + theta*w<sub>t-1</sub>

- w<sub>t</sub>：当期白噪声（新冲击）
- w<sub>t-1</sub>：上期冲击
- theta：冲击残留影响系数

直观理解：
AR 是“看过去价格”；MA 是“看过去噪声”。
MA 模型描述的是“冲击尾巴效应”：一个消息冲击不会立刻消失，会短期残留。

关键特点：
1. MA(q) 只保留前 q 期冲击影响，记忆长度有限；
2. 在标准可逆条件下建模稳定，实务上常用于处理短记忆噪声结构。

### 2) ARMA模型：AR + MA 合体
ARMA = AutoRegressive Moving Average（自回归移动平均）。

以 ARMA(1,1) 为例：
x<sub>t</sub> = phi*x<sub>t-1</sub> + w<sub>t</sub> + theta*w<sub>t-1</sub>

- phi*x<sub>t-1</sub>：价格惯性（AR部分）
- w<sub>t</sub> + theta*w<sub>t-1</sub>：冲击残留（MA部分）

它解决的问题：
真实市场通常既有惯性也有冲击余波，单AR或单MA往往不够，ARMA能同时刻画两类信息。

### 3) AR / MA / ARMA 核心对比
1. AR(1)：看过去观测值，记忆会衰减但理论上可持续很长。
2. MA(1)：看过去噪声，记忆短，超过阶数后影响消失。
3. ARMA(1,1)：同时看“过去观测值 + 过去冲击”，更贴近实盘数据。

### 4) 量化场景对应
1. 趋势行情：AR更擅长抓惯性延续。
2. 事件冲击后余波：MA更擅长抓短期残留影响。
3. 常态市场：惯性与冲击并存，ARMA通常更实用。

### 5) 记忆口诀
- AR：看过去价格，抓惯性
- MA：看过去噪声，抓冲击尾巴
- ARMA：两者合体，更接近真实市场
