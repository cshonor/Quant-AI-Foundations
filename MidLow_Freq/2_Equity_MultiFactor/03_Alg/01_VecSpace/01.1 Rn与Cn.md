# 1.A **R**<sup>n</sup> 与 **C**<sup>n</sup>

## 一、核心概念速记

1. **复数**  
   形式：a + bi（a, b ∈ **R**），全体复数集合：**C**。

2. **数域 F**  
   **F** 特指 **R**（实数）或 **C**（复数）；F 中元素称为**标量**。

3. **组（List）**  
   - 形式：(x<sub>1</sub>, x<sub>2</sub>, …, x<sub>n</sub>)，元素**有序、可重复**；  
   - 与集合的区别：集合无序、元素互异；组有序、允许重复。

4. **F**<sup>n</sup> **空间**  
   所有分量取自 **F**、长度为 n 的组构成的集合，是线性代数最基础的向量空间。

---

## 二、**F**<sup>n</sup> 两大基本运算（必考）

设 u = (u<sub>1</sub>, …, u<sub>n</sub>)，v = (v<sub>1</sub>, …, v<sub>n</sub>) ∈ **F**<sup>n</sup>，λ ∈ **F**。

1. **加法**（对应分量相加）  
   u + v = (u<sub>1</sub> + v<sub>1</sub>, u<sub>2</sub> + v<sub>2</sub>, …, u<sub>n</sub> + v<sub>n</sub>)

2. **标量乘法**（数乘，分量分别相乘）  
   λu = (λu<sub>1</sub>, λu<sub>2</sub>, …, λu<sub>n</sub>)

---

## 三、易混辨析（高频）

| 对比 | 组 | 集合 |
| :--- | :--- | :--- |
| 顺序 | 有序 | 无序 |
| 重复 | 允许 | 元素互异 |
| 例子 | (1, 2) ≠ (2, 1)；(1, 1) 合法 | {1, 2} = {2, 1} |

- **F 二选一**：全书若无特殊说明，**F** = **R** 或 **C**，标量从二者中选取。
- **直观**：**R**<sup>2</sup> = 平面 (x, y)；**R**<sup>3</sup> = 空间 (x, y, z)；**C**<sup>n</sup> = 分量为复数的 n 元组。

---

## 四、一句话总结

**F**<sup>n</sup> 是有序数组的集合，配备**分量相加**与**标量逐分量数乘**，是向量与向量空间的入门模型。

---

## 五、八条基础规则（后续公理化）

对任意 u, v, w 与标量 λ, μ：

1. u + v = v + u  
2. (u + v) + w = u + (v + w)  
3. 存在 0，使 v + 0 = v  
4. 对每个 v 存在 −v，使 v + (−v) = 0  
5. λ(u + v) = λu + λv  
6. (λ + μ)v = λv + μv  
7. λ(μv) = (λμ)v  
8. 1 · v = v  

---

## 六、应用直观

- 因子暴露向量、收益向量、风险参数向量，均可视为 **R**<sup>n</sup> 中的点或向量。

---

## 补充要点

- **复数运算**：(a + bi)(c + di) = (ac − bd) + (ad + bc)i；例 (2 + 3i)(4 + 5i) = −7 + 22i。  
- **几何**：**R**<sup>2</sup>、**R**<sup>3</sup> 中加法对应平行四边形法则。  
- **易错**：符号 0 可能是标量 0，也可能是零向量 (0, …, 0)，需看上下文。  
- **拓展**：任意域（Fields）；相空间、ML 特征向量等 **R**<sup>n</sup> 实例。
