# 1.C 子空间与直和

## 一、前置概念

- **线性空间 = 向量空间**，叫法不同，含义完全一致。  
- **R**<sup>3</sup> 即日常三维直角坐标系，几何直观最强。

---

## 二、子空间

### 1. 判定三大条件（充要）

设 U 是线性空间 V 的子集，U 是**子空间** ⟺ 同时满足：

1. 包含**零向量** **0**（必过原点）；  
2. **加法封闭**：∀ u<sub>1</sub>, u<sub>2</sub> ∈ U，u<sub>1</sub> + u<sub>2</sub> ∈ U；  
3. **数乘封闭**：∀ u ∈ U、任意标量 k，ku ∈ U。

**通俗**：在 U 内做加法、数乘，向量不会跑出 U，且一定经过原点。

### 2. **R**<sup>3</sup> 几何实例

| 对象 | 是否子空间 |
| :--- | :---: |
| 过原点的直线、平面 | ✅ |
| 不过原点的直线、平面 | ❌（不含 **0**） |

### 3. 易错点

- 两个子空间的**并集**，一般**不是**子空间。  
- 形如 f′(2) = b 的可微函数集，**仅当 b = 0** 时为子空间（b ≠ 0 不含零元）。

---

## 三、子空间的和

### 1. 定义

设 U<sub>1</sub>, U<sub>2</sub> 为 V 的子空间：

U<sub>1</sub> + U<sub>2</sub> = { u<sub>1</sub> + u<sub>2</sub> | u<sub>1</sub> ∈ U<sub>1</sub>, u<sub>2</sub> ∈ U<sub>2</sub> }

从两子空间各取向量相加，所有结果构成的集合。

### 2. 基础结论

多个子空间的和仍是**子空间**，且是同时包含各 U<sub>j</sub> 的**最小**子空间。

---

## 四、直和（核心）

### 1. 普通和 vs 直和

| | 普通和 | 直和 |
| :--- | :--- | :--- |
| 重叠 | 可有非零公共向量 | 仅 **0** 相交（两子空间时） |
| 分解 | 可能不唯一 | **唯一**，记 U<sub>1</sub> ⊕ U<sub>2</sub> |

### 2. 两子空间直和（最常用）

U<sub>1</sub> + U<sub>2</sub> 为直和 ⟺ **U<sub>1</sub> ∩ U<sub>2</sub> = {0}**

等价：和空间中向量分解唯一；零向量只能 **0 = 0 + 0**。

### 3. **R**<sup>3</sup> 例子

U<sub>1</sub> = x 轴，U<sub>2</sub> = y 轴 → 交于 (0, 0, 0) → **直和**；平面内向量唯一拆为 x 轴向量 + y 轴向量。

### 4. 三个及以上子空间（易错）

**U<sub>1</sub> ∩ U<sub>2</sub> ∩ U<sub>3</sub> = {0} 不能判定直和！**

**充要条件**：U<sub>1</sub> + … + U<sub>m</sub> 为直和 ⟺ 对每个 i，

U<sub>i</sub> ∩ (U<sub>1</sub> + … + U<sub>i−1</sub> + U<sub>i+1</sub> + … + U<sub>m</sub>) = {**0**}

**反例**（**F**<sup>3</sup>）：U<sub>1</sub> = {(x, y, 0)}，U<sub>2</sub> = {(0, 0, z)}，U<sub>3</sub> = {(0, y, y)}。三者整体交仅 **0**，但非直和：

(0, 0, 0) = (0, 1, 0) + (0, 0, 1) + (0, −1, −1)

---

## 五、逻辑脉络

1. **子空间**：三条判定；  
2. **子空间的和**：组合多个子空间；  
3. **直和**：要求分解唯一；  
4. 两子空间用「交 = {**0**}」；多子空间用「每个 U<sub>i</sub> 与其余子空间和的交 = {**0**}」。

---

## 六、速记背诵清单

1. 子空间三条件：含 **0**、加法封闭、数乘封闭。  
2. **R**<sup>3</sup>：过原点直线/平面 ✅；不过原点 ❌。  
3. 子空间的和仍是子空间。  
4. 两子空间直和 ⟺ 交 = {**0**} ⟺ 分解唯一。  
5. 多子空间直和**不能只看整体交集**。  
6. 子空间**并集**一般不是子空间。
