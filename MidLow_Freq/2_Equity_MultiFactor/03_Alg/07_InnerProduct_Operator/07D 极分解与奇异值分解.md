# 7.D 极分解与奇异值分解

## 核心知识点与关键定义

- **极分解**：T = S√(T\*T)，S 为等距同构。
- **奇异值**：√(T\*T) 的本征值（按代数重数重复）；均 ≥ 0。
- **奇异值分解 (SVD)**：用两组规范正交基与奇异值表示 T 对任意向量的作用。

## 重点结论与公式要点

- 任意 T ∈ L(V) 存在等距 S 使 **T = S√(T\*T)**。
- 奇异值 = √(T\*T) 的本征值，非负。
- 奇异值 s<sub>1</sub>, …, s<sub>n</sub> 时，存在规范正交基 e<sub>1</sub>, …, e<sub>n</sub> 与 f<sub>1</sub>, …, f<sub>n</sub> 使
  Tv = s<sub>1</sub>⟨v, e<sub>1</sub>⟩f<sub>1</sub> + … + s<sub>n</sub>⟨v, e<sub>n</sub>⟩f<sub>n</sub>。
- 仅当 T 为正算子时，奇异值才等于 T 的本征值；一般奇异值来自 T\*T 的非负平方根。

## 案例数据与易错细节

- **案例**：T(z<sub>1</sub>, z<sub>2</sub>, z<sub>3</sub>, z<sub>4</sub>) = (0, 3z<sub>1</sub>, 2z<sub>2</sub>, −3z<sub>4</sub>)；T\*T 本征值 9, 4, 0, 9 → 奇异值 3, 3, 2, 0；T 本征值仅 0, −3，奇异值揭示真实「拉伸」系数。
- **易错**：对角化只用**一组**基；SVD 允许定义域基 e<sub>j</sub> 与值域基 f<sub>j</sub>**不同**，故对**任意**算子成立。

## 逻辑脉络与关联推演

- 复数 z = e<sup>iθ</sup>|z| → T = S√(T\*T) → 奇异值 → SVD；克服对角化对算子类型的限制。

## 预留拓展空间

- SVD 在 PCA、图像压缩、低秩近似、机器学习特征提取中的应用。
