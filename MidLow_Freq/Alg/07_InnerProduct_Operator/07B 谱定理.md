# 7.B 谱定理

## 核心知识点与关键定义

- **复谱定理**：**C** 上内积空间的算子分解。
- **实谱定理**：**R** 上内积空间的算子分解。
- **规范正交对角化**：存在规范正交基使 M(T) 为对角阵 ⟺ 存在由 T 本征向量组成的规范正交基。

## 重点结论与公式要点

- **复谱定理**：T 有规范正交本征基 ⟺ T **正规**。
- **实谱定理**：T 有规范正交本征基 ⟺ T **自伴**。
- 自伴 T，b<sup>2</sup> < 4c 时 T<sup>2</sup> + bT + cI 可逆。
- 非零实内积空间上自伴算子**必有**本征值（且为实数）。

## 案例数据与易错细节

- **案例**：**C**<sup>2</sup> 上正规 T 的矩阵 [[2, −3], [3, 2]]，本征值 2 ± 3i，可规范正交对角化。
- **易错**：实空间上**正规**算子不一定能规范正交对角化；实空间须**自伴**才保证实本征值与对角化。

## 逻辑脉络与关联推演

- 舒尔定理 + 正规性 → 复谱定理；实空间用二次式正定性证自伴有实本征值 + 归纳 → 实谱定理。

## 预留拓展空间

- 谱分解 T = λ<sub>1</sub>P<sub>1</sub> + … + λ<sub>k</sub>P<sub>k</sub> 的投影形式证明。
