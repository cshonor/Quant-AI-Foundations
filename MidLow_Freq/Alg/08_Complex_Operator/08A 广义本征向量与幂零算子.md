# 8.A 广义本征向量与幂零算子

## 核心知识点与关键定义

- **零空间序列**：{0} = null T<sup>0</sup> ⊂ null T<sup>1</sup> ⊂ … ⊂ null T<sup>k</sup> ⊂ …
- **广义本征向量**：λ 为本征值，v ≠ 0 且存在 j ≥ 1 使 (T − λI)<sup>j</sup>v = 0。
- **广义本征空间 G(λ, T)**：相应于 λ 的广义本征向量全体加 0；是子空间。
- **幂零算子**：存在 k 使 N<sup>k</sup> = 0。

## 重点结论与公式要点

- 若 null T<sup>m</sup> = null T<sup>m+1</sup>，则此后不变；且 m ≤ n = dim V 时必停止。
- **V = null T<sup>n</sup> ⊕ range T<sup>n</sup>**。
- G(λ, T) = null(T − λI)<sup>dim V</sup>。
- 不同本征值的广义本征向量**线性无关**。
- 幂零 N 满足 **N<sup>dim V</sup> = 0**；存在基使 M(N) 为严格上三角（对角及以下为 0）。

## 案例数据与易错细节

- **案例**：T(z<sub>1</sub>, z<sub>2</sub>, z<sub>3</sub>) = (4z<sub>2</sub>, 0, 5z<sub>3</sub>) 在 **F**<sup>3</sup> 中 null T + range T 非直和，但 null T<sup>3</sup> ⊕ range T<sup>3</sup> = **F**<sup>3</sup>。
- **易错**：无「广义本征值」——(T − λI)<sup>j</sup> 不单 ⟹ T − λI 不单 ⟹ λ 是 T 的本征值。
- **易错**：广义本征向量须 v ≠ 0；G(λ, T) 作为子空间**含** 0。

## 逻辑脉络与关联推演

- 零空间序列停止增长 → 广义本征向量补全张成 → 幂零结构 → 为全空间直和分解铺路。

## 预留拓展空间

- 微分方程久期项 t<sup>k</sup>e<sup>λt</sup> 与广义本征向量的对应。
