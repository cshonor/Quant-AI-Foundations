# 向量空间的线性映射
## 1. 线性映射定义
设 V, W 是数域 F 上的两个向量空间，映射 T: V -> W 若对任意 u, v 属于 V、任意 lambda 属于 F，同时满足：
1. 可加性：T(u + v) = T(u) + T(v)
2. 齐次性：T(lambda*v) = lambda*T(v)
则称 T 为从 V 到 W 的线性映射。

## 2. 基础推论
1. T(0) = 0，线性映射必然把零向量映射为零向量。
2. 保持线性组合：T(向量线性组合) = 对应像向量的同系数线性组合。

## 3. 常见线性映射举例
- 矩阵乘法变换
- 空间旋转、投影、镜像变换
- 微积分中的求导、积分算子
- 零映射、恒等映射

## 4. 线性映射的集合
全体 V -> W 的线性映射，本身也构成一个向量空间，记作 L(V, W)。

---

## 补充梳理（教材要点）

### 核心知识点与关键定义

- **线性映射**：T: V → W 满足加性 T(u + v) = Tu + Tv 与齐性 T(λv) = λ(Tv)。
- **L(V, W)**：V → W 全体线性映射的集合；在其上定义 (S + T)(v) = Sv + Tv，(λT)(v) = λ(Tv)，自身构成向量空间。
- **乘积**：S ∈ L(V, W)，T ∈ L(U, V) 时 (ST)(u) = S(Tu) ∈ L(U, W)。

### 重点结论与公式要点

- T(0) = 0。
- 基 v<sub>1</sub>, …, v<sub>n</sub> 与 w<sub>1</sub>, …, w<sub>n</sub> ∈ W 给定后，存在**唯一** T 使 T(v<sub>j</sub>) = w<sub>j</sub>。
- 乘积满足结合性、(S<sub>1</sub> + S<sub>2</sub>)T = S<sub>1</sub>T + S<sub>2</sub>T，单位元 I 满足 TI = IT = T。

### 案例数据与易错细节

- **案例**：零映射、恒等映射、微分 Dp = p′、积分、乘 x<sup>2</sup>、序列向后移位。
- **易错**：φ(x, y) = x<sup>2</sup> + y<sup>2</sup> 非线性；|·| 齐性成立但加性不成立。
- **易错**：ST ≠ TS 常见（先微分再乘 x<sup>2</sup> ≠ 先乘 x<sup>2</sup> 再微分）。

### 逻辑脉络与关联推演

- 线性映射保持代数结构；映射本身也可代数化；基上的取值完全决定映射。

### 预留拓展空间

- 泛函分析中有界线性算子；有限维与无限维下连续性差异。
