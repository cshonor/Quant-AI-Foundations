# 对偶空间
## 1. 对偶空间定义
向量空间 V 的对偶空间 V' 定义为：
V' = L(V, F)。
也就是：所有从 V 映到数域 F 的线性函数全体，本身也构成向量空间。

## 2. 对偶基
若 (v1, ..., vn) 是 V 的一组基，则可以唯一构造出 V' 的一组对偶基 (phi1, ..., phin)，满足：
φ<sub>i</sub>(v_j) = delta_ij，即当 i = j 时取 1，当 i 不等于 j 时取 0。

## 3. 核心维数结论
有限维空间下：dim(V') = dim(V)。

## 4. 补充说明
对偶空间属于线性代数进阶抽象内容，入门阶段、侧重算子与应用的学习，可以延后处理。

## 补充梳理（教材要点）

### 核心知识点与关键定义

- **线性泛函**：V → **F** 的线性映射；**对偶空间 V′** = L(V, **F**)。
- **对偶基**：基 v<sub>1</sub>, …, v<sub>n</sub> 对应 φ<sub>j</sub> ∈ V′，满足 φ<sub>j</sub>(v<sub>k</sub>) = δ<sub>jk</sub>。
- **对偶映射 T′**：T ∈ L(V, W) ⟹ T′ ∈ L(W′, V′)，T′(φ) = φ ∘ T。
- **零化子 U<sup>0</sup>**：V′ 中把 U 映为 0 的泛函全体；**转置** (A<sup>t</sup>)<sub>k,j</sub> = A<sub>j,k</sub>。

### 重点结论与公式要点

- dim V′ = dim V；(ST)′ = T′S′。
- dim U + dim U<sup>0</sup> = dim V。
- null T′ = (range T)<sup>0</sup>；T 满 ⟺ T′ 单；T 单 ⟺ T′ 满。
- **M(T′) = (M(T))<sup>t</sup>**；行秩 = 列秩 = 秩。

### 案例数据与易错细节

- **案例**：φ(p) = ∫<sub>0</sub><sup>1</sup> p(x)dx 或 φ(p) = p′(5) 都是线性泛函。
- **易错**：T′ 方向 W′ → V′；复合对偶顺序反转 (ST)′ = T′S′，对应 (AB)<sup>t</sup> = B<sup>t</sup>A<sup>t</sup>。
- **易错**：有限维 V ≅ V′ **依赖基**；V ≅ V″ 有**自然**同构（不依赖基）。

### 逻辑脉络与关联推演

- 线性泛函 = 标量化观测；对偶映射 = 观测的前推；零化子连接原映射与对偶映射的核/像；转置解释行秩 = 列秩。

### 预留拓展空间

- **R**<sup>n</sup> 中泛函 ↔ 超平面（等高线）的几何可视化。
- 内积空间里兹表示定理：V 与 V′ 的内在等同。
