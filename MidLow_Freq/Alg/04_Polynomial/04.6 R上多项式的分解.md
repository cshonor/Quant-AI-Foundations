# 4.6 **R** 上多项式的分解

## 核心知识点与关键定义

- **共轭零点成对**：实系数 p 若 λ ∈ **C** 为零点，则 λ̄ 也是零点。
- **实二次不可约**：x<sup>2</sup> + bx + c（b, c ∈ **R**，b<sup>2</sup> < 4c）在 **R** 上不可分解为一次因子。

## 重点结论与公式要点

- **R 上完全分解**：非常数 p ∈ P(**R**) 可唯一分解为一次因子与二次不可约因子之积：
  p(x) = c(x − λ<sub>1</sub>)⋯(x − λ<sub>m</sub>)(x<sup>2</sup> + b<sub>1</sub>x + c<sub>1</sub>)⋯(x<sup>2</sup> + b<sub>M</sub>x + c<sub>M</sub>)，
  λ<sub>j</sub> ∈ **R**，b<sub>j</sub><sup>2</sup> < 4c<sub>j</sub>。
- **配对公式**：(x − λ)(x − λ̄) = x<sup>2</sup> − 2(Re λ)x + |λ|<sup>2</sup>（实系数二次项）。

## 案例数据与易错细节

- **案例**：1 + x<sup>2</sup> 在 **R** 无零点，自身为二次不可约项。
- **证明共轭性**：a<sub>k</sub> ∈ **R** ⟹ a<sub>k</sub> = ā<sub>k</sub>；p(λ) = 0 取共轭得 p(λ̄) = 0。
- **易错**：基本定理对 **R** 不成立；实分解必含二次不可约项 → 实算子理论需二维不变子空间或复化。

## 逻辑脉络与关联推演

- 从 **C** 分解回到 **R**：共轭根配对 → 二次实因子 → 实域分解底线是「一次 + 二次」。

## 预留拓展空间

- 第 9 章实算子：复化 (Complexification) 与二维不变子空间。
