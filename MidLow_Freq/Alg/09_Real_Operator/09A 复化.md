# 9.A 复化

## 核心知识点与关键定义

- **复化 V<sub>C</sub>**：V 为实向量空间，V<sub>C</sub> = V × V，元素 u + iv（u, v ∈ V）。
- **V<sub>C</sub> 运算**：(u<sub>1</sub> + iv<sub>1</sub>) + (u<sub>2</sub> + iv<sub>2</sub>) = (u<sub>1</sub> + u<sub>2</sub>) + i(v<sub>1</sub> + v<sub>2</sub>)；(a + bi)(u + iv) = (au − bv) + i(av + bu)；u ↔ u + i0。
- **算子复化 T<sub>C</sub>**：T ∈ L(V)，T<sub>C</sub>(u + iv) = Tu + iTv ∈ L(V<sub>C</sub>)。
- **实算子特征多项式**：q(T) 定义为 T<sub>C</sub> 的特征多项式。

## 重点结论与公式要点

- V 的（实）基也是 V<sub>C</sub> 的（复）基；**dim V<sub>C</sub> = dim V**（维数不翻倍）。
- 同一基下 **M(T) = M(T<sub>C</sub>)**（实矩阵 = 复矩阵）。
- 非零有限维实空间上每个 T 有**一维或二维**不变子空间（借 T<sub>C</sub> 本征值 a + bi 构造 U = span(u, v)）。
- T 与 T<sub>C</sub> 的**极小多项式相同**，系数为实数。
- λ 为 T<sub>C</sub> 本征值 ⟺ λ̄ 也是，且**重数相等**。
- **奇数维**实空间上每个 T 至少有一个**实**本征值。
- **凯莱-哈密顿**：q(T) = 0。

## 案例数据与易错细节

- **案例**：实矩阵 A，Tx = Ax 的复化即 **C**<sup>n</sup> 上 z ↦ Az。
- **案例**：T(x<sub>1</sub>, x<sub>2</sub>, x<sub>3</sub>) = (2x<sub>1</sub>, x<sub>2</sub> − x<sub>3</sub>, x<sub>2</sub> + x<sub>3</sub>) 的本征值 2, 1 + i, 1 − i 各重 1。
- **易错**：复化后 dim 在 **C** 上等于原 dim 在 **R** 上，不是 2 倍。
- **易错**：**C** 上算子必有一维不变子空间；**R** 上只能保证一维或二维不变子空间。

## 逻辑脉络与关联推演

- 借 V<sub>C</sub> 使用第 8 章完备理论 → 共轭成对 → 回投 **R**（奇数维必有实根、凯莱-哈密顿等）。
