# 13 Backtesting Methodology

> **教材来源**：新建占位（待补充教材）


> 回测方法学。防止过拟合的"保命"知识——CTA 策略的回测可信度直接决定实盘生死。

## 学习目标

- 理解为什么绝大多数回测都是"谎言"
- 掌握防止过拟合的统计学方法
- 能设计可信的回测流程

## 核心知识点

### 1. 过拟合的本质
- **PBO（Probability of Backtest Overfitting）**：Bailey & López de Prado 提出
  - 组合对称交叉验证（CSCV）：将回测切分为 N 块，对称组合训练/测试集
  - 如果最优策略在训练集的表现排名在测试集中随机分布，则 PBO 高
- **曲线拟合 vs 噪声拟合**：
  - 参数越多，拟合越好，但泛化越差
  - 10 年日线回测 ≈ 2500 个数据点，超过 5 个参数就危险

### 2. 样本外检验
- **训练/测试分割**：前 70% 训练，后 30% 测试
- **Walk-Forward Analysis（滚动前推）**：
  1. 在 [t0, t1] 上优化参数
  2. 在 [t1, t1+Δ] 上测试
  3. 滚动窗口：在 [t0+Δ, t1+Δ] 上重新优化
  4. 在 [t1+Δ, t1+2Δ] 上测试
  5. 拼接所有测试期收益，评估整体表现
- **Purged K-Fold Cross Validation**（López de Prado）：
  - 在金融时间序列上，标准 K-Fold 会泄漏信息
  - 需要在训练/测试边界处"清除"重叠的观测（purging）
  - 再加 embargo 防止自相关泄漏

### 3. 多重检验问题
- **数据窥探（Data Snooping）**：测试了 N 个策略，选出表现最好的——即使全是随机策略，最好的那个也会"显著"
- **White's Reality Check / Hansen's SPA Test**：校正多重检验后的显著性
- **Deflated Sharpe Ratio（DSR）**：
  - 考虑了策略尝试次数 N 和非正态收益后的 Sharpe Ratio 校正
  - DSR = [SR × √(T-1) - (1-γ)×φ^{-1}(1-P)] / √[1 - γ×φ^{-1}(1-P) - (1-γ)×φ^{-1}(1-P)²]
  - T = 样本数，γ = 偏度，P = 多重检验 p-value

### 4. 回测偏差来源
| 偏差类型 | 方向 | 原因 |
|:---|:---|:---|
| 幸存者偏差 | 高估收益 | 只回测了现存合约/品种，退市的不在样本中 |
| 前视偏差 | 高估收益 | 用了未来才知道的信息（如用收盘价做盘中决策） |
| 滑点低估 | 高估收益 | 忽略了市场冲击成本（大单推高/压低价格） |
| 手续费低估 | 高估收益 | 忽略佣金、交易所费用、印花税 |
| 流动性偏差 | 高估收益 | 回测假设无限流动性，实盘远月可能成交不了 |
| 参数过拟合 | 高估收益 | 在历史数据上调参，未来不复现 |

### 5. 交易成本建模
- **佣金**：固定/按手数
- **滑点模型**：
  - 线性：slippage = k × volume
  - 平方根：slippage = k × √volume（Almgren-Chriss 模型）
- **买卖价差**：bid-ask spread 作为隐性成本
- **市场冲击**：大单对价格的影响

### 6. 回测质量检查清单
- [ ] 是否有前视偏差？（所有信号只用 t 时刻已知信息）
- [ ] 是否包含交易成本？（佣金 + 滑点 + 冲击）
- [ ] 是否做了样本外检验？（Walk-Forward 或 CSCV）
- [ ] 参数数量是否合理？（参数 / 数据点 < 1%）
- [ ] 是否做了敏感性分析？（参数微调后表现是否稳定）
- [ ] 是否考虑了幸存者偏差？（包含退市品种）
- [ ] 是否做了多重检验校正？（DSR 或 White's RC）
- [ ] 不同市场环境下表现如何？（牛市/熊市/震荡市）

## CTA 特有的回测问题

- **主力合约拼接**：连续合约的拼接方式（回退调整/比率调整）会影响信号
- **展期成本**：多头展期在升水市场（contango）会持续亏损
- **日内 vs 日频**：日内策略回测需要 tick 级数据，日频回测可能失真
- **参数鲁棒性**：趋势跟踪策略参数（均线周期）在 1970-2020 的表现一致性
