# 第 9 章 · 数据犯罪：Statistics Done Wrong

## 本章讲什么

前八章教的是**怎么用**统计工具，这一章反过来讲**怎么会被这些工具骗**。开头那个例子很典型：

> 《纽约邮报》标题：「名人推崇的饮食与心脏病死亡风险升高相关」——16:8 饮食法使
> 心脏病死亡风险增加 **91%**。

这项研究分析了两万多名美国成年人、中位随访八年。但真正的拆穿出现在**第八段**：
数据来自患者**自我报告**，而且没有任何饮食营养方面的信息。没有临床试验式的控制，
患者完全可能每天抽两包烟、吃十袋薯片，标题照样把责任归给「不吃早餐」。

> 耸动的媒体标题本身就是第 9 章要讲的全部五种偏差的集大成：
> 混杂变量、选择偏差、回忆偏差、确认偏差，以及（对研究方法而言）幸存者偏差。

本章没有一道计算题，但每一条都能做成可判决的实验——这恰好是 math-lab 最擅长的部分。

## 要点

### 混杂变量：看不见的那个 Z

X 与 Y 相关，可能是 X→Y、Y→X、Z→两者的任意一个。书里的例子是「孩子出现在厨房」
与「饼干消失」，真正的 Z 是溜进厨房的柯利犬格雷西。

CBDF 量化版本（Math-lab 实测，4000 样本）：

| 相关系数 | 值 |
| :--- | ---: |
| 边际 r(X, Y) | **0.7397**（强相关） |
| 一阶偏相关 r(X, Y \| Z) | **−0.0057** |
| 偏相关的 p 值（df = n−3） | **0.719**（完全不显著） |
| r(X,Z)·r(Y,Z) = 0.7411 | 与边际 r 相差仅 **0.2%** |

⇒ 当 X = aZ + ε₁、Y = bZ + ε₂ 时，边际相关近似就等于 r(X,Z)·r(Y,Z)。
这条近似给了一个快速体检法：**如果边际相关能被两段相关的乘积解释掉，
它就不是因果线索。**

**辛普森悖论**是混杂的极端形态（书没讲，但它是同一件事）：两个子组内部斜率
都严格是 +2，合并之后整体斜率是 **−0.147**。这时看汇总表做决策，结论与看分组表完全相反。
此时混杂变量甚至不是一列数据，而是**「属于哪一组」这个标签本身** —— 它常被忽略，
正因为它在二维表里是一行而不是一列。

### 五种数据偏差

| 偏差 | 定义 | 书上的例子 | 本节的定量对照 |
| :--- | :--- | :--- | :--- |
| 选择偏差 | 群体自我选择进入样本 | 航空公司只调查自己的乘客 | **75% vs 真实 30%**（见下） |
| 回忆偏差 | 只记得鲜明/有利的数据 | 忘了茶水间那片披萨；怀旧滤镜 | — |
| 锚定偏差 | 过度依赖最先收到的信息 | 定价算法锚在发售首日 | — |
| 确认偏差 | 只收集与期望一致的数据 | 只发有利于本机构的研究 | 见 9.2 的 p-hacking |
| 幸存者偏差 | 只分析存活样本 | 只研究 30 家最强公司 | **纯噪声池里照样出夏普 2.35 的明星** |

**选择偏差**（贝叶斯算得清清楚楚）：

$$P(\text{喜欢} | \text{乘坐}) = \frac{0.70 \times 0.30}{0.70 \times 0.30 + 0.10 \times 0.70} = \frac{0.210}{0.280} = \mathbf{0.75}$$

而全市场的真实值是 **30%**。蒙特卡洛 20 万人复核算出 0.7523，与公式相差 2.3e−03。
注意**这不是说谎**：每位乘客都真诚地回答了问题，是抽样框自己把结论做歪了。

**幸存者偏差**（CTA 上最致命的一种）：

| 量 | 实测 |
| :--- | ---: |
| 策略池规模 | 10,000 个，每人 3 年日频，**真实期望严格为 0** |
| 全体平均观测夏普 | −0.0039 |
| 观测夏普的标准差 | **0.5815**（理论 1/√3 = 0.5774） |
| 最亮的那颗的观测夏普 | **2.348** |
| 观测夏普 > 1.0 的数量 | 441 个（4.41%），它们的平均观测夏普 **1.241** |

关键公式：**观测夏普的标准差 = 1/√T**（T 以年计）。于是 3 年数据给自己 ±0.58、
10 年才收到 ±0.32。一个跑了 3 年、观测夏普 0.6 的策略，**根本区分不了它是真 alpha 还是运气**。

LinkedIn 那篇「30 家最强上市公司的 10 个特质」的毛病就在于：它采集了成功者，
却**结构上无法**采集失败者。书里点得很准：这是第 8 章说的类别不平衡的极端版本 ——
正例（失败）一个都采不到。

### p-hacking：五种手法都能被量化

| 实验 | 实测结果 |
| :--- | :--- |
| 20 个纯噪声变量里至少一个 p<0.05 | **65.9%**（理论 1−0.95²⁰ = 0.6415） |
| 在同一个测试集上反复挑最好的模型（K=1000） | 测试分数从 0.50 涨到 **0.7504**，而同一批模型在全新数据上只有 **0.5059** |
| 换成验证集来挑（三层划分） | 验证集虚高到 0.7545，但从未参与的测试集回落到 **0.4966** |
| 允许自己删 5 个「异常点」 | **74.5%** 的纯噪声数据集能熬到 p<0.05（一个都不删时是 4.5%） |
| 试了 K 个变量后最显著那个的期望 p 值 | 就是 **1/(K+1)** —— 与具体是哪个变量无关 |

**剂量-反应曲线**（这条最值得记住）：

| K（你试了多少次） | 1 | 10 | 100 | 1000 |
| ---: | ---: | ---: | ---: | ---: |
| 报告口：旧测试集精度 | 0.5038 | 0.6208 | 0.6965 | **0.7504** |
| 真相：全新数据精度 | 0.5051 | 0.4910 | 0.4999 | **0.5059** |

全部数据都是标准正态噪声与掷硬币标签，**没有任何一个模型有真实预测力**。
唯一发生的事情是「看了一眼再决定报告哪一个」。

**剔除离群点的分叉路径**（Ronald Coase 那句「折磨数据够久它终将招供」的定量版）：

| 允许删除的点数 | 0 | 1 | 2 | 3 | 4 | 5 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 能熬到 p<0.05 的比例 | 4.5% | 12.3% | 24.7% | 37.7% | 58.2% | **74.5%** |

删 0 个时是 4.5%，正好复现名义的 5% —— **出问题的从来不是 p 值，是那条被藏起来的、
通向最后一次删除的路径。** 三个 p-hacking 手法里，「剔除离群值」本身是合法的
（书自己给了通宵开车的例子），分界线只有一条：**规则是否写在看到结果之前**。

### 运行域、数据覆盖与漂移

书用两个例子讲同一件事：**你的型号不知道自己出了运行域**。

**挑战者号 O 形环**（23 次飞行的真实数据）：

| 分段 | 航行次数 | 出现热损伤的比例 |
| :--- | ---: | ---: |
| 温度 ≥ 66°F | 19 | **21.1%** |
| 温度 < 66°F | **4** | **100.0%** |

Fisher 精确检验 p = **0.0079**（样本这么小，卡方近似是不能用的）。
低温段的四个点是：53°F(2 个)、57°F(1 个)、58°F(1 个)、63°F(1 个)。
**信号一直都在，但它是被 4 个点撑起来的** —— 而它们恰好落在最不该稀疏的那一端。

发射当天是 31°F。就这一天，只用域内数据拟合给 **71.0%**，加上那 4 个低温样本后给 **99.9%**，
差 **28.9 个百分点**。而在覆盖域内（70°F）两台模型分别是 22.7% 与 29.2%，几乎没区别。
⇒ **分歧不是在别处普遍存在的，它是被外推创造出来的。**

**数据漂移**：

| 评估口径 | 合成的机制反转市场 | BTC 日线真实数据 |
| :--- | ---: | ---: |
| 训练集（就拿 modeled 段） | 0.9233（很好看） | — |
| 时间序切分（用前段训练、后段测试） | **0.0711** | 0.4920 |
| 随机划分（打乱） | 0.4764（「还过得去」） | 0.5048 ± 0.0174 |

**低于 0.5 是关键证据**：模型不是「失去预测力」，而是在**系统性地反向预测**。
而随机划分把这个危险完全藏起来了（0.4764），因为抽样时两个机制各占一半、彼此抵消。
⇒ **评价任何时序模型都必须按时间切分，不能打乱。**

教学性的否定结果：**BTC 那一项我没能演示出漂移**。随机划分 0.5048 与时序切分 0.4920
相差 1.29pp，还不到随机划分自身噪声的 1σ（σ = 0.0174）。原因不神秘：这个模型本身的
准确率就在 0.50 附近，**没有预测力可以漂**。「诊断不出漂移」与「不存在漂移」是两件必须分开写的事。

## CTA / 量化关联

| 本章结论 | CTA 上的直接后果 |
| :--- | :--- |
| 观测夏普标准差 = 1/√T | 3 年数据给自己 ±0.58 的噪声；**自负夏普 0.6 的策略谈不上 alpha**。反驳任何「看我三年回测」的话术只需乘这个数 |
| 10,000 个纯噪声策略里最亮的能到夏普 2.35 | 任何「还在跑的策略排行榜」都自带幸存者偏差；清盘/停更/亏光的早就自己下架了。看排行榜前先问：**下架的那批在哪里** |
| K 从 1 到 1000，测试分数 0.50→0.75，而新数据始终 0.50 | 调参就是自己的 p-hacking。篮子里有多少组候选，就要多砍多少 optimism |
| 三层划分能修复（0.4966） | 样本是**消耗品**，每被你看一次就少一层。最后那段时间只能做一件事：报数，然后不许再改 |
| 合成反转市场：时序切分 0.0711 < 0.5 | 机制切换时模型会**反向**预测。风控上必须有一路「模型此刻是否在域内」的开关 |
| 挑战者号：4 个点撑起救命的信号；域内外推差 28.9pp | 写下 ODD：波动率区间、趋势/震荡状态、流动性、是否主力合约。**出了这些状态主动停手**，而不是让模型照常下单 |
| 剔除 5 个点 → 74.5% 显著 | 「这段数据有异常我剔了」必须事前写进规则；回测里的事后删样本是最难自查的作弊 |

**被实测纠正/补充的直觉**：

1. 我以为第 9 章是纯定性章节，没什么可判决的 —— **实测它反而是全书最适合做数字实验的一章**。
   每一条告诫都能变成一个具体的百分率。
2. 我原以为「幸存者偏差」只是「少了对照组」这么简单 —— **实测它有精确的量级**：
   观测夏普的标准差 = 1/√T，这个数决定了「池子里最亮的那个能亮到多高」。
3. 我原以为在 BTC 上能演示出漂移 —— **实测没有**：随机划分与时序切分只差 1.29pp，
   在噪声内。**「没测出漂移」不等于「没有漂移」，这个检查项我按否定结果如实记录了。**
4. 我原以为多重比较 ≈ 64% 会随种子有明显抖动 —— 确实会（不同种子 ±1.8pp），
   所以把重复次数提到 12,000 次才稳到 ±0.5pp。**Monte Carlo 小节自己也要遵守样本量纪律。**
