# 第 8 章 · 逻辑回归与分类

## 本章讲什么

第 7 章的输出是连续值（103.5 华氏度），这一章的输出是**标签**（是 / 否、垃圾邮件 / 正常邮件）。
整章回答三件事：

- **怎么把「概率」压进 [0, 1]**：sigmoid 那条 S 曲线，以及它的指数部分为什么恰好是**对数几率**；
- **怎么知道模型能用在没见过的数据上**：训练/测试划分、K 折交叉验证；
- **为什么准确率是个骗人的指标**：混淆矩阵的四个格子、精确率与召回率，
  以及能把这件事算成账的那条恒等式。

全章的暗线其实是**样本量决定尺子的刻度**——上一章用偏差-方差讲过一遍，
这一章在「评估」这个环节又讲了一遍。

> 本章笔记的数字全部来自可复现实验（见文末「可运行实验」），不是抄书。
> 书里用 scikit-learn，本章实验**完全手写 numpy**（IRLS + ROC/PRC/AUC），因为本机没有 sklearn。

## 要点

### 逻辑回归：25 天没午睡的数据

| 量 | 值 | 书上的值 |
| :--- | ---: | ---: |
| β₀（截距） | **−7.058995** | −7.0587 |
| β₁（斜率） | **2.204795** | 2.2047 |
| Newton–Raphson 迭代次数 | 9 | — |
| P(4.78 小时会崩溃) | **0.9701** | 0.9701 |
| P(4)、O(4)、ln O(4) | 0.8532 / 5.8130 / **1.7601** | 同 |
| ln O(x) ≡ β₀ + β₁x 的误差 | **6.66e−16** | — |
| O(6)/O(4) | **82.2357** | 82.22 |
| 决策边界（p = 0.5） | **3.2017 小时** | 3.202 |

**对数几率是本章最值钱的一句话**：

$$\ln\frac{p}{1-p} = \beta_0 + \beta_1 x$$

σ(z) 那个「看起来只是为了把值域压到 0~1」的指数项，在反解之后就是赔率的对数。
于是 β₁ 有了确切读法：**每多 1 小时，赔率乘以 e^2.2048 ≈ 9.07 倍**（注意是赔率，不是概率）；
多熬 2 小时就是 9.07² ≈ 82 倍。

这也解释了为什么默认阈值取 0.5：它正是 ln O = 0（赔率 1:1）的那一点，
**不是人为挑的数字，而是模型自己的结构决定的**。

### 为什么不直接用直线

书上画了张图说「直线很难看」。实测给了两条更硬的理由：

| 判据 | 最小二乘直线 | 逻辑回归（MLE） |
| :--- | ---: | ---: |
| 观测范围内的预测值域 | **[−0.2037, 1.1880]** | ⊂ (0, 1) |
| log-loss（越小越好） | 0.2694 | **0.2330** |
| Brier（= 平方误差，直线自己的主场） | 0.0825 | **0.0774** |

关键点：直线是在平方误差意义下的**最优解**，却连平方误差都没赢。
因为把 0.85 这种值喂给平方损失会系统性吃亏（真实标签为 1 时罚 0.0225，接近 1 只罚 0.0025）。
还有一层更隐蔽的：0/1 标签的方差是 p(1−p)，天生**异方差**，
所以直线的参数估计虽然在数值上能算，标准误和 p 值那一整套推论已经失效了。

### 训练/测试划分：这把尺子有多粗

25 个样本做 test_size = 1/3 ⇒ **测试集只有 9 个**。后果是可算的：

| 事实 | 实测 |
| :--- | :--- |
| 准确率可能取值的个数 | **5 个**（5/9 … 9/9） |
| 相邻取值的间隔 | **恰好 1/9 = 11.11 个百分点** |
| 100 次随机划分的分布 | 均值 0.8667、标准差 **0.0981** |
| 最好 / 最差 | 1.0000 / 0.5556，**跨度 44.4 个百分点** |

⇒ **一个样本 = 11 个百分点**。书上那次 0.7778 与 0.8889 之间，只差一个娃娃当天到底崩没崩。

书里还报了交叉验证的 0.8796 ± 0.0065。**这个 0.0065 必须小心**：

| 不同随机划分下 | 实测 |
| :--- | :--- |
| 能否复现书的 0.8796 / 0.0065 | **能**，某个种子精确命中（三折 8/9、7/8、7/8） |
| 20 个种子里折间 std 的范围 | **0.0065 ~ 0.1768，相差 27 倍** |
| CV **均值**跨种子的标准差（这才是真正的不确定性） | **0.0393** |

交叉验证确实把单次 holdout 的标准差从 0.0981 压到了 0.0393（降了 60%）——这是它真正的价值。
但书上那个 0.0065 是**折与折之间的一致性**（这几份数据难易是否相当），
不是「我的准确率有多少把握」，后者是前者的 6 倍。

### 准确率的账

混淆矩阵的四个格子带来的核心结论，可以写成一个闭式解：

$$\text{acc}_{model} - \text{acc}_{永远预测负} = \pi \cdot \text{recall} \cdot \frac{2\cdot\text{precision}-1}{\text{precision}}$$

（π = 正例占比。实测 18 组配置全部落在公式上，最大偏差 1.67e−16。）

这个式子把「准确率为什么没用」的两个原因一次性说清了：

1. **π 因子**：目标事件越罕见，准确率能用来区分模型的空间就越小；
2. **(2·precision−1) 因子**：精确率的门槛线是 **50%**，不是「看起来挺高」。
   precision 恰好 0.5 时，**模型的准确率与什么都不做的分类器完全相同，且与 π 无关**
   （实测 π 从 0.5 到 0.01 六档，增益均为 0.00e+00）。

狼来了那个例子的具体数字：

| 系统 | TP / FP / TN / FN | 准确率 | 精确率 | 召回率 |
| :--- | :--- | ---: | ---: | ---: |
| 供应商甲 | 0 / 1 / 98 / 1 | 0.9800 | **0** | **0** |
| 永远喊「没狼」 | 0 / 0 / 99 / 1 | **0.9900** | — | 0 |
| 供应商乙 | 36 / 2 / 451 / 11 | 0.9740 | 0.9474 | 0.7660 |

⇒ 准确率更高的那家，**一次狼都没抓到**。

### F1 的对称陷阱

作者引 Emmanuel Maggiori 批评 F1「武断地给两者同等权重、调和平均还不直观」。
实测补了一条更硬的证据：**把精确率与召回率互换，F1 一个字都不变**。

| 模型 | precision | recall | F1 | 500 天里的 (TP, FP, FN) |
| :--- | ---: | ---: | ---: | ---: |
| 甲（谨慎） | 0.947 | 0.764 | **0.845714** | (36, 2, **11**) |
| 乙（激进） | 0.764 | 0.947 | **0.845714**（差 0.00e+00） | (45, **14**, 2) |

几何平均同样完全对称（0.850593）。两个模型在羊场是两种生意，F1 判它们是同一个。

### ROC / PRC / AUC

| 结论 | 实测（seed=3 的一次 1/3 划分，测试集 34 个） |
| :--- | :--- |
| 梯形法 AUC vs Mann–Whitney 秩和 AUC | **0.9249084249 对 0.9249084249，差 0.00e+00** |
| 书上一次运行的 AUC / AP | 0.9774 / 0.9658（34 个样本换个划分差几个点是正常的） |
| 阈值 0.20 → recall / precision | 1.000 / 0.650 |
| 阈值 0.90 → recall / precision | 0.692 / **0.818** |
| Youden J 最优点 | 阈值 **0.4271**（TPR 0.923、FPR 0.143），换算回业务语言 **2.92 小时** |
| PRC 的无技巧基线 | 常数预测的 AP **恰好 = prevalence**（0.3824） |

AUC 的第二个定义解释了一切：**它是随机取一个正例和一个负例，正例得分更高的概率**。
它只关心排序，既不看概率绝对值，也不看正负样本各有多少——
所以它在不平衡数据上会**装作没事**。这是本章最重要的发现：

| 负样本复制倍率 | 正例占比 | ROC-AUC | PRC 的 AP | Brier |
| ---: | ---: | ---: | ---: | ---: |
| ×1 | 0.3824 | **0.924908** | 0.8431 | 0.1137 |
| ×2 | 0.2364 | **0.924908** | 0.7607 | 0.1262 |
| ×5 | 0.1102 | **0.924908** | 0.6333 | 0.1371 |
| ×10 | 0.0583 | **0.924908** | 0.5449 | 0.1415 |
| ×30 | 0.0202 | **0.924908** | 0.4512 | 0.1448 |
| ×100 | 0.0062 | **0.924908** | **0.4065** | **0.1460** |

模型一次都没重训，只是重复了负样本。**AUC 小数点后六位纹丝不动，AP 掉了 0.4366，
Brier 涨了 28%（概率已经不校准）。** 这就是「不平衡时用 PRC」的确切含义，而且是可以直接量出来的。

同样的机制还有一个所有人都读错过的地方：**最优阈值不是模型的属性，而是损失函数的属性**。
Youden J 偷偷假设了 FP 与 FN 一样贵；若不是，最优点就挪。

## CTA / 量化关联

| 本章结论 | CTA 上的直接后果 |
| :--- | :--- |
| 9 个测试样本 ⇒ 准确率只有 5 个可能取值，一格 11.1pp | 年触发 20 次的信号，胜率的最小刻度就是 5 个百分点。「胜率 42%→47%」常常只是 1 笔交易的差别 |
| 单次 holdout 标准差 0.098、跨度 44pp | 单次 train/test 的夏普/胜率不能作为调参依据；必须重复划分或走 walk-forward |
| 折间 std 0.0065 vs CV 均值 std 0.0393（差 6 倍） | 别把 K 折的折间标准差当置信区间用，那会把方差看小一个量级 |
| 准确率蕴含的账：关键因素永远是 precision 与 π | 期指日内信号正样本常常 < 5%，此时「不做」的对照就有 95%+ 准确率；**accuracy 永远是无效指标** |
| precision = 胜率、recall = 覆盖率、FN = 踏空、FP = 假突破 | 趋势策略 40% 胜率照样赚钱 ⇒ 优化目标从来不是precision，而是每笔期望与回撤 |
| 负样本 ×100 ⇒ AUC 不变、AP 崩 0.44、Brier 涨 28% | **AUC ≈ 因子的排序能力（IC 的兄弟），AP ≈ 这个触发频率下实际能赚的钱**。日频信号 AUC 稳在 0.93 让人兴奋，AP 会告诉你多数上车信号是假突破 |
| 排序对、数值错 | 用 AUC 选信号可以；**拿它输出的概率算 Kelly 仓位会直接爆**（需先做 prevalence 平移） |
| 34 个样本上随机标签 AUC 的 95% 区间是 [0.313, 0.716] | 看到「测试集 AUC = 0.68，n = 30」先问零分布有多宽 |

配套代码在 `math-lab/grokking-statistics/ch08-逻辑回归与分类/`，**3 节 / 22 个判定项全部 PASS**。
共享模块 `_logistic.py` 里手写了 IRLS、混淆矩阵、ROC/PRC、两种 AUC、AP、K 折——**没有 sklearn**。

| 小节 | 判决的命题 | 实测结论 |
| :--- | :--- | :--- |
| `8.1-逻辑回归与对数几率：S曲线下面藏着一条直线.py` | 手写 IRLS 能否复现系数 / 三个预测值 / 对数几率恒等式 / 几率比是否与起点无关 / 直线为什么错 | β₀ = −7.058995、β₁ = 2.204795（书 −7.0587 / 2.2047）；P(4.78) = 0.9701；**ln O ≡ β₀+β₁x 误差 6.66e−16**；O(6)/O(4) = O(4.5)/O(2.5) = e^{2β₁} = 82.2357；直线预测值域 [−0.2037, 1.1880] 且两项损失都输给 MLE |
| `8.2-训练测试划分与准确率的陷阱.py` | holdout 的分辨率 / 划分噪声 / CV 是否复现书上的 std / 狼例子 / 准确率的闭式账 / F1 的对称性 | 9 个样本 ⇒ **5 个取值、间隔 1/9**；100 次划分跨度 44.4pp；书的 0.8796/0.0065 **能被精确命中**但折间 std 跨种子差 27 倍；恒等式验证误差 1.67e−16 且 precision=0.5 时增益恒为 0；**F1 对调后差 0.00e+00** |
| `8.3-阈值ROC与PRC：不平衡时AUC为什么装作没事.py` | AUC 两定义是否一致 / 零分布有多宽 / 阈值是否真在交换 / Youden 最优点 / 不平衡下 AUC 与 AP 的分歧 / 概率是否仍然校准 / PRC 基线 | 两种 AUC 差 0.00e+00；随机标签 95% 区间 [0.313, 0.716]；0.20 → (P 0.650, R 1.000)，0.90 → (P 0.818, R 0.692)；Youden 点在 0.4271 = **2.92 小时**；**AUC 全程 0.924908 不变、AP 0.8431→0.4065、Brier 涨 28%** |

**被实测纠正/补充的直觉**：

1. 我以为「不平衡时恒负分类器的准确率会超过真模型」——**实测这个命题是错的**。
   只要 recall ≠ 0，模型的准确率就一定高于恒负。真正成立的是那条恒等式：
   差距被 π 压缩，且 precision ≤ 0.5 时归零。**准确率的毛病不是「会被打败」，
   而是「会把天差地别的两个模型压成同一个数」。**
2. 我以为随机打分的 AP 会低于 prevalence 基线——
   **实测反而高 0.0410**（0.4233 vs 0.3824）。原因是 AP ≡ Σ(i/kᵢ)/n_pos，
   而 E[i/kᵢ] > i/E[kᵢ]（Jensen）把面积往上抬。
   **⇒ PRC 的虚线比「随机」还严格**，不能拿柱子直接跟虚线比。
3. 书上那句「这次运行 AUC = 0.9774」看起来是个稳定数字——**实测同一份数据换个划分能到 0.9249**，
   而且随机标签的 AUC 有 ±0.20 的噪声。**单次 AUC 本身也需要报置信区间。**
4. 书上只说 0.5 是默认阈值，没说它是有来历的——**它其实是模型结构决定的**：
   ln O = 0 的那一点。相比之下 Youden 最优点的 2.92 小时早了近 20 分钟，
   差的就是 FP 与 FN 的相对成本。

## 衔接

第 8 章把「样本内的高分可以凭空制造」从回归推到了分类，
并且**第一次出现了「同一个模型换个阈值就是另一笔生意」**这个想法：

- A/B 两面：作者在这一章已经明说，K 折交叉验证也**不是万能药**——
  第 9 章会更进一步：即使训练/测试划分做得再规范，
  p-hacking、多重比较、数据漂移、幸存者偏差仍然能让样本外分数虚高；
- 另一面：本章所有讨论都建立在「标签是真的」这个前提上。
  到了第 9 章会看到，光是**选择哪些特征、什么时候停止搜索**，
  就足以把一个纯噪声模型推到测试集上的高分。
