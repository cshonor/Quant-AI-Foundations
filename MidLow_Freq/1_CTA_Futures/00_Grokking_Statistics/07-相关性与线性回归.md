# 第 7 章 · 相关性与线性回归

## 本章讲什么

前面六章都在处理**单个变量**。这一章开始看两个变量怎么一起动：

- **相关性**：用一个数字（皮尔逊 r）给两个变量的线性关系强度打分；
- **线性回归**：拟合一条直线，用 x 预测 y；
- **模型评估与诊断**：残差、SSE、R²、RMSE，以及「什么时候不该信这条线」。

作者的态度贯穿全章：**相关系数本身也是一个检验统计量**（自带 p 值），
而任何统计量都有使用前提；他用了大量篇幅讲「相关不等于因果」和「插值 vs 外推」。

> 本章笔记的数字全部来自可复现实验（见文末「可运行实验」），不是抄书。

## 要点

### 皮尔逊相关系数

书上例题（温度 °F vs 运动饮料销售额，n = 10）：

| 量 | 值 |
| :--- | ---: |
| r（手算 / scipy 一致） | **0.988907** |
| 检验统计量 t = r/√((1−r²)/(n−2)) | 18.8306 |
| 双尾 p（df = n−2 = 8） | **6.538e−08**（书 0.0000000654） |

注意自由度是 **n−2** 而不是 n−1 —— 因为用了两个变量，不确定性多扣一格。

**r 的取值范围 −1~1**，作者给的读数是「±0.5 中等、±1 极强」。但这个读数有个陷阱：

| 样本量 | r = 0.5 的 p 值 | 结论 |
| ---: | ---: | :--- |
| 10 | 0.1411 | **不显著** |
| 20 | 0.0248 | 显著 |
| 50 | 2.18e−04 | 显著 |
| 100 | 1.18e−07 | 显著 |
| 200 | 4.77e−14 | 显著 |

反过来，α = 0.05 所需的 |r| 门槛：

| n | 10 | 30 | 100 | 500 |
| ---: | ---: | ---: | ---: | ---: |
| 门槛 | 0.632 | 0.361 | 0.197 | **0.088** |

⇒ **统计显著 ≠ 有经济意义**。n = 500 的日频样本里 |r| = 0.088 就能显著，而它只解释 0.8% 的方差。

### 皮尔逊的四条假设（逐条打过）

书上给了：线性、连续且近似正态、同方差、无严重离群值。作者引了 Anscombe 四重奏当警示。**这套警告实测全部成立**：

**① Anscombe 四重奏**（4 组 n=11 的数据）：

| 组 | r | 斜率 | 截距 | R² | 加二次项后 SSE 下降 | 最大残差/平均残差 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: |
| I（真直线） | 0.8164 | 0.5001 | 3.000 | 0.6665 | 6.23% | 2.29 |
| II（抛物线） | 0.8162 | 0.5000 | 3.001 | 0.6662 | **100.00%** | 1.96 |
| III（一个离群点） | 0.8163 | 0.4997 | 3.002 | 0.6663 | 5.50% | **4.53** |
| IV（一个点撑全场） | 0.8165 | 0.4999 | 3.002 | 0.6667 | 0.00% | 2.04 |

四个数据集的四个统计量**一模一样**（r 的极差只有 2.85e−4），形状却分别是直线、抛物线、带离群点、以及「10 个点叠在 x = 8 上再加一个孤立点」。**r 和 p 值都不看图，看图的人必须是你自己。**

**② 离群值**（n = 30 的干净线性数据，只追加 1 个点）：

| 指标 | 干净 | 加一个离群点 |
| :--- | ---: | ---: |
| 皮尔逊 r | 0.9871 | **0.7439**（掉 24.3 个百分点） |
| 斯皮尔曼 ρ | — | 0.9886（**只掉 0.15 个百分点**） |

作者推荐的秩相关实测有效得惊人。但金融数据里的离群点通常不是错误，而是最重要的那几天——**删之前先判断它是错误数据还是真实事件**。

**③ 伪相关（本章最贵的一条）**：两个**完全独立生成**的随机游走（n = 500，3000 组）：

| 指标 | 两个独立随机游走 | 同长度 iid 序列（对照） |
| :--- | ---: | ---: |
| \|r\| > 0.5 的比例 | **38.83%** | 0.000% |
| 互做 OLS 得到 p < 0.05 的比例 | **88.70%**（名义 5%） | — |
| \|r\| 的标准差 | 0.486 | 理论 1/√n = 0.045 |

根因：皮尔逊相关假设样本点独立，而随机游走每个点都带着上一个点的全部信息 ⇒ 有效样本量远小于 n，p 值被系统性低估（Granger–Newbold 伪回归）。**配对交易的直接后果：在不协整的两个品种上看到 ρ = 0.8 就开仓，那个 0.8 大概率只是两条各自游走的产物。**

### 最小二乘：为什么闭式解就是最低点

书上给了损失函数 SSE = Σ(yᵢ − ŷᵢ)²，以及闭式解：

```
m = (n·Σxy − Σx·Σy) / (n·Σx² − (Σx)²)
b = ȳ − m·x̄
```

复现（温度/销量，n = 10）：

| 量 | 值（书） |
| :--- | ---: |
| 斜率 m | 9.740871（9.74） |
| 截距 b | −405.2598（−405.26） |
| 斜率标准误 | 0.5173 |
| SSE | 5477.67（5477.72） |
| RMSE | 23.4044 |
| R²（r² 与公式两条路一致到 2e−16） | 0.9779 |

手写闭式解与 scipy 相差 |Δm| = 1.78e−15。**「它是最低点」实测：2000 组随机扰动（Δm~N(0,0.5)、Δb~N(0,30)）让 SSE 无一例外上升**，最小的一次也增加了 1.26。这就是线性模型相对深度学习的最大优势——没有局部最优、不需要调学习率。

### 插值 vs 外推（同一条线，两个世界）

书上的原话：「你已经走出了地图的边缘，伙计。那里有怪物！」截距 −405.26 意味着 0°F 卖出 −405 单位饮料。

**用一个已知真值弯曲的过程量化**（真值 = 饱和曲线，观测区间 [52, 102]）：

| 区间 | R² / RMSE |
| :--- | ---: |
| 观测区间内 | R² = **0.9856**、RMSE = 20.13（一切指标都健康） |
| 低温侧外推 [20, 45] | RMSE = **227.6**（17.1 倍） |
| 高温侧外推 [108, 140] | RMSE = **242.3**（18.2 倍） |
| 0°F 的外推值 | **−568.9**（真值 0.5） |

**真实 BTC 日线**（384 个滚动窗口；两个任务都用 60 个训练点、都预测 20 个点）：

| 任务 | RMSE 中位数 |
| :--- | ---: |
| 插值（补中间的洞） | 0.0703 |
| 外推（推向未来） | 0.1015（**1.51 倍**，76.6% 的窗口更差） |

> 这个 1.51 倍比我预想的小 —— 根因是 BTC 接近随机游走，这条直线本来就没什么解释力。
> 换个读法反而更不舒服：**在几乎没有信号的资产上，只要把预测点从「中间」挪到「未来」，
> 同一个模型的误差就已经涨了 50%**。

### 过拟合与偏差-方差权衡

作者的反问：为什么不选一个足够灵活的模型把 SSE 压到 0？答案就是过拟合。实测（真值 sin(2πx)，σ = 0.25，训练 30 点，200 次重复）：

| 多项式次数 | 训练 RMSE | 测试 RMSE |
| ---: | ---: | ---: |
| 1 | 0.484 | — |
| **3** | — | **0.127（最优）** |
| 12 | 0.187 | 28.658（**225 倍**） |
| 11（= n−1，n = 12 的子实验） | **4.76e−05**（残差归零） | 4.56e6 |

**偏差-方差分解**（固定预测点 x₀ = 0.75，200 次重拟合）：

| 次数 | 偏差² | 方差 | 合计 MSE |
| ---: | ---: | ---: | ---: |
| 1 | 0.2630 | 0.0183 | 0.3438 |
| 3 | — | — | **0.0708（最优）** |
| 5 | ≈0（最小） | — | — |
| 12 | 0.549 | **103.7（涨 5660 倍）** | 104.3 |

关键在**量级不对称**：偏差能被复杂度压下去的空间有界（最多压到真值），而方差没有上界。

### R² 的陷阱：加特征无条件抬高样本内 R²

因变量是**纯噪声**（n = 200，每个 k 重复 40 次取平均）：

| 特征数 k | 样本内 R² | 理论 k/(n−1) | 调整后 R² | 样本外 R² |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 0.005 | 0.005 | −0.0005 | −0.008 |
| 5 | 0.027 | 0.025 | +0.0020 | −0.041 |
| 20 | 0.103 | 0.101 | +0.0027 | −0.115 |
| 50 | 0.241 | 0.251 | −0.0142 | −0.333 |
| 100 | **0.505** | 0.503 | +0.0058 | **−1.072** |

不是「可能」，是**数学必然**：多加一列就多一个自由度去逼近残差，OLS 保证 SSE 不上升。
在完全没有信号的因变量上，**100 个随机特征就能拿到 R² ≈ 0.5**。

**真实 BTC 日收益**（1998 个日收益，前 70% 训练，20 个特征）：

| 特征 | 样本内 R² | 样本外 R² |
| :--- | ---: | ---: |
| **纯高斯噪声** | 0.0151 | −0.0212 |
| 过去 20 天的收益 | 0.0214 | −0.0227 |
| 基准（常数预测 RMSE） | — | 0.02311 vs 模型 0.02337 |

两个看起来天差地别的特征集，样本内是同一个量级，**真正把它们分开的只有样本外**——而样本外都 ≤ 0。

## CTA / 量化关联

| 本章结论 | CTA 上的直接后果 |
| :--- | :--- |
| 两个独立随机游走 \|r\|>0.5 占 38.8%，OLS 显著率 88.7% | 价格序列的相关/回归毫无意义；**先差分或先做协整检验**，第 7 章这句口号不管用 |
| r 与 p 都不看图（Anscombe） | 任何「因子 IC 排名第一就上」的流程都是错的；必须看散点图、看残差、看是否由单点撑起 |
| 离群点让皮尔逊掉 24 个百分点、秩相关只掉 0.15 | 有极端行情的日子不能删；用秩相关/稳健回归，或者分段报告 |
| 样本量决定「显著」的门槛（n=500 时 \|r\|=0.088 就显著） | 大样本上的显著性毫无含金量，必须同时报效应大小（R²、RMSE、经济含义） |
| 外推 RMSE 是插值的 1.51 倍（真值弯曲时是 17~18 倍） | 用线性趋势外推目标价是循环论证；**评估未来只能用 walk-forward 样本外** |
| 训练误差能一路走到 0，测试误差是 U 形 | 策略参数越细、样本内夏普越高，样本外往往越差；选参数必须用留出段 |
| 加特征无条件抬高样本内 R²（100 个噪声特征 → 0.5） | 因子筛选若以样本内 R²/IC 为标准，留下来的必定混进一批纯运气；**筛选也只能在训练段内做** |
| 偏差-方差：方差涨 5660 倍，偏差只降到 0 | 复杂模型的失败模式是「不稳定」而不是「不准」；优先选结构约束强的模型 |

## 可运行实验（math-lab）

配套代码在 `math-lab/grokking-statistics/ch07-相关与线性回归/`，**3 节 / 18 个判定项全部 PASS**。

| 小节 | 判决的命题 | 实测结论 |
| :--- | :--- | :--- |
| `7.1-皮尔逊相关系数：0.9889能信多少.py` | 复现 r/p / Anscombe 是否同统计量 / 离群值威力 / 强相关≠显著 / 伪相关 | r = 0.988907、p = 6.538e−08；四重奏 r 极差 2.85e−4 但二次项探针把组 II 抓出（SSE 下降 100%）；离群点让皮尔逊掉 24.3pp、Spearman 只掉 0.15pp；**伪相关 \|r\|>0.5 占 38.83%、OLS 显著率 88.70%** |
| `7.2-最小二乘与插值外推.py` | 复现 6 个数字 / 闭式解是否全局最优 / 真值弯曲时外推的代价 / BTC 上插值 vs 外推 | 六个数字全部复现；**2000 次扰动 SSE 无一例外上升**；弯曲真值下区间内 R² 0.9856、两侧外推 RMSE 17~18 倍；BTC 上外推 RMSE 是插值的 **1.51 倍**（76.6% 窗口更差） |
| `7.3-过拟合与偏差方差权衡.py` | 训练/测试误差的 U 形 / 偏差方差分解 / 噪声特征抬高 R² / BTC 因子能否预测 | 训练 RMSE 单调降到 0.187、测试最差 225 倍；插值（deg=n−1）训练 4.76e−05 而测试 4.56e6；方差涨 **5660 倍**；100 个噪声特征样本内 R² **0.505**、样本外 −1.072；BTC 上噪声与滞后收益样本内同级、样本外都 ≤ 0 |

**被实测纠正/补充的直觉**：

1. 我以为「相关系数 0.5 是中等强度」这句话自带含义 —— **实测它必须配样本量读**：n=10 时 p=0.14 不显著，n=200 时 p=5e−14。
2. 我以为外推在真实数据上会糟糕好几倍 —— **实测只有 1.5 倍**（BTC 近随机游走，直线本就没什么解释力）。构造数据里的 17~18 倍发生在**真值弯曲**的情形，别把两个数字混着用。
3. 我以为「随机特征解释不了多少方差」 —— **实测 100 个噪声特征能拿 R²≈0.5**，与理论 k/(n−1) 完全吻合。样本内的 R² 是可以凭空制造的。

## 衔接

第 7 章把「两个变量怎么一起动」和「用 x 预测 y」都装进了工具箱，也留下了两条边界：

- **它只处理连续、线性的问题**。下一章（逻辑回归）要处理的是「是 / 否」这种分类输出——
  届时评估指标会换一套（混淆矩阵、精确率、召回率），而「准确率具有误导性」会成为一个新陷阱；
- **样本内指标可以凭空制造**这件事在本章只是开了个头。第 9 章会把它推到极致：
  p-hacking、多重比较、幸存者偏差，本质上都是「样本内的高分」的不同伪装。
