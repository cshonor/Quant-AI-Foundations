# 第 5 章 · 样本量超能力（置信区间与 t 分布）

## 本章讲什么

上一章建立了 CLT，这一章把它变成能用的工具：**不再报一个点估计，而是报一个带置信水平的范围**。内容包括 CLT 的应用、临界 Z 值、均值与比例的置信区间、小样本下的 t 分布，以及这条线最常被误读的一句话——「95% 置信」到底是什么意思。

作者的态度很明确：优秀的统计学家以**不确定性**而非绝对确定性作答，他们乐于给出数值范围而不是单一数值。

> 本章笔记的数字全部来自可复现实验（见文末「可运行实验」），不是抄书。

## 要点

### 应用 CLT：三个性质与一条账单

| 性质 | 表述 |
| :--- | :--- |
| 中心 | 样本均值的**均值** = 总体均值 μ |
| 散布 | 样本均值的**标准差**（标准误）= σ / √n |
| 形状 | 总体正态 ⇒ 样本均值精确正态；总体不正态 ⇒ n 够大时近似正态 |

书上例题：健康成年人体温 μ = 98.2°F、σ = 0.73°F，抽 **n = 31** 人，问平均体温低于 98°F 的概率。
**实测 6.3578%**，书上答案 0.0636 —— 复现无误。

真正要紧的是那条**散布公式的账单**：误差范围 ∝ 1/√n，所以精度是**平方根**买的：

| 想要的精度 | 需要的样本量 |
| :--- | :--- |
| 维持现状（n = 30） | 1× |
| 误差减半 | **4×** |
| 误差降到 1/10 | **100×** |
| 只给 2 倍样本 | 误差仅降到 0.707× |

这条换算书里轻轻带过，但它决定了所有实验设计的成本线：

- 实测 SE 对 n 的幂律斜率 = **−0.4997**（理论 −0.5），与 σ/√n 的最大相对偏差 0.74%；
- 换成真实右偏数据（NOAA 龙卷风宽度，偏度 3.30）重抽样，斜率仍是 **−0.500** —— 偏度完全不影响散布；
- ⇒ 从 n=30 加到 n=100，花掉 3.3 倍数据，误差只从 ±0.261 降到 ±0.143。

**要区分两件事**：CLT 管的是**散布（方差）**，不管**形状（尾部）**。第 4 章已经量过：同样是 n=31，中心部分很准，尾部还是被正态低估 70%。

### 置信区间的构造

**点估计**是单一数值（如样本均值 x̄）；**置信区间**是「范围 + 置信水平」。

```
误差范围 m = z · σ/√n          （σ = 总体标准差）
CI = x̄ ± m
```

**临界 Z 值**：要让标准正态曲线中心对称区域面积为 A，取 `norm.ppf(1 - (1-A)/2)`。A = 0.95 ⇒ **±1.959964**。

书上屏幕使用时间的例子（x̄ = 7.5 h、σ = 2.5 h、n = 100）：

| 置信水平 | 临界 Z | 区间 |
| :--- | ---: | :--- |
| 95% | 1.960 | (7.010, 7.990) |
| 99% | 2.576 | (6.856, 8.144) |
| 99.9% | 3.291 | (6.677, 8.323) |

**n 从 100 加到 1000**（置信水平不变）：95% 区间从 (7.010, 7.990) 缩到 **(7.345, 7.655)** —— 宽度减少约 68%，正好对应 √10 的倒数 0.316 倍。**想更宽的范围就提置信度，想更窄的范围就加样本，二者不能兼得。**

### 「95% 置信」是什么意思（本节最贵的一句）

> 书的原话：CI 像**捞鱼的网**。95% 置信意味着 95% 的网能捞到鱼，**不是**说某一张特定的网有 95% 的概率捞到鱼。

这句话可以被数值判决 —— 把区间公式当机器，反复喂新样本，数真值被包住的比例（**覆盖率**）：

| 条件 | 实测覆盖率 |
| :--- | ---: |
| σ 已知，n = 10 / 31 / 100（M = 3 万次） | **95.00% / 95.05% / 95.05%** |
| σ 未知用 z = 1.96，n = 31 | 94.07% |
| σ 未知用 z = 1.96，n = 5 | 87.80% |
| 换成 t 区间，n = 5 / 10 / 31 | **95.08% / 94.98% / 94.89%** |

**为什么它会失败**：这里的概率是关于「这套程序」的长期频率，不是关于「这个具体区间」的。单个区间要么包住真值要么没包住，没有概率可谈。回测报告里那句「策略年化 18% ± 3%（95% CI）」被读成「真收益有 95% 概率落在 15%~21%」，是最常见的误读。

### t 分布：给「σ 未知」补差价

σ 是总体参数，现实中几乎不可能知道（知道 σ 基本等于知道了整个总体）。用样本标准差 s 顶替后，同一个 z = 1.96 就开始漏水：

| n | z 区间的真实覆盖率 | t 临界值 | 区间要宽多少 |
| ---: | ---: | ---: | ---: |
| 5 | 87.84% | 2.776 | +41.7% |
| 10 | 91.84% | 2.262 | +15.4% |
| 31 | 94.07% | 2.042 | +4.2% |
| 100 | 94.72% | 1.984 | +1.2% |

**换成 t 分布后，覆盖率精确回到 95%**（实测 n=5 时 95.08%）。所以 t 分布不是「近似正态的另一条曲线」，它是**给 σ 的不确定性补差价**的量。自由度 DOF = n − 1。

**蜡烛例题**（n = 10、x̄ = 42.24 h、s = 3.62 h、99% 置信）：

- t 临界值（dof=9）= **3.2498**，CI = **(38.520, 45.960)** —— 复现书上答案；
- 若顺手写成 z = 2.5758，区间会窄成 (39.291, 45.189)，**宽度少 20.7%**；
- 这道题叠加了两个因素（99% 高置信 + n=10 小样本），是最容易算错的一处。

### 「n > 30 就用正态代替 t」的账单

书上（以及绝大多数教材）都写：样本量超过 30 时 t 与正态没有显著差异。实测这句话**要付费**：

| n | 用 z 代替 t 的覆盖率 | 亏损 |
| ---: | ---: | ---: |
| 10 | 91.84% | 3.16 个百分点 |
| **31** | **94.07%** | **0.93 个百分点** |
| 100 | 94.72% | 0.28 个百分点 |
| 500 | 94.94% | 0.06 个百分点 |

要亏到 0.1 个百分点以下，需要 **n ≥ 500**。既然现代计算里查 t 临界值和查 z 一样廉价，这里**没有省事的理由**。

### 前提破了，t 也救不了

t 分布常被讲成「小样本的万能补丁」，它只修「σ 未知」这一个漏洞。把「总体正态」这个前提拿掉（龙卷风宽度，偏度 3.30）：

| n | z 区间 | t 区间 | bootstrap 百分位 |
| ---: | ---: | ---: | ---: |
| 10 | 78.3% | 81.2% | 78.0% |
| 31 | 87.1% | 88.0% | 88.1% |
| 100 | 92.4% | 92.6% | 92.5% |
| 300 | 94.3% | 94.4% | 94.3% |

**bootstrap 完全没有救回来**（我原本以为它在这种偏斜数据上会更好）。原因：百分位 bootstrap 的区间宽度直接取自「这个样本自己的离散程度」，小样本既偏又窄，bootstrap 分布照抄了这两点。

⇒ 一句话边界：**CLT 管散布，t 管 σ 的估计误差，谁都不管总体形状。**形状问题只能靠更大的 n（n=300 才 94.3%）或换模型。

### 比例的置信区间

公式只改标准误一处：

```
CI = p̂ ± z·√( p̂(1−p̂)/n )
```

书上例题：抽 100 人、55 人玩游戏 ⇒ **95% CI = (0.452, 0.648)** —— 复现无误（Wilson 0.4524~0.6439、精确 0.4473~0.6497，此例三者几乎重合）。

**经验法则 np ≥ 5 且 n(1−p) ≥ 5 —— 它担保的是「分布像正态」，不担保覆盖率。**把它拿去结算：

| p | n | np | Wald 覆盖率 | Wilson | 精确 | Wald 越界率 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0.10 | 30 | 3.0 | **80.6%** | 97.4% | 99.2% | 60.7% |
| **0.05** | **100** | **5.0** | **87.7%** | 96.5% | 98.2% | **25.0%** |
| 0.05 | 30 | 1.5 | **78.4%** | 93.9% | 98.4% | 72.7% |
| 0.50 | 100 | 50 | 94.3% | 94.3% | 96.5% | 0% |

**p=0.05 / n=100 恰好满足 np=5 这条规则，Wald 覆盖率只有 87.7%，而且 25% 的样本会算出负的下界**（「胜率可能是 −3%」）。越界率那一列更说明问题：p=0.05 / n=30 时 72.7% 的样本给出荒谬区间。

**Wald 的覆盖率还是锯齿状振荡的**：p = 0.20，n 从 20 到 200，覆盖率在 88.3% ~ 95.4% 之间跳（最大相邻反向跳变 > 2 个百分点），标准差是 Wilson 的好几倍。**加样本不一定让覆盖率变好。**

**Wilson 区间**改动极小（中心点往 0.5 拉一点、把 p 本身的不确定性算进标准差），代价接近零，收益是覆盖率和稳定性都回来，且**天然不越界**。

**精度的样本量公式**（p = 0.5 时最坏）：

| 目标误差范围 | 需要样本量 |
| :--- | ---: |
| ±5% | 385 |
| **±3%** | **1068** |
| ±1% | 9604 |

政治民调标配 1000 人不是行业习惯，是 (1.96/0.06)² ≈ 1068 这条曲线的直接结果。想把精度翻一倍（±3% → ±1.5%），样本要从 1068 涨到 4269 —— 又是 4 倍，与均值的 √n 账单同源。

## 代码示例

```python
import numpy as np, scipy.stats as stats

# ① CLT：样本均值的分布    SE = σ/√n
mu, sigma, n = 98.2, 0.73, 31
se = sigma / np.sqrt(n)
print(f"P(样本均值 < 98.0) = {stats.norm.cdf(98.0, mu, se):.4f}")   # 0.0636

# ② 临界 Z 值与置信区间（σ 已知）
A = 0.95
z = stats.norm.ppf(1 - (1 - A) / 2)                # 1.959964
mean, sd, n = 7.5, 2.5, 100
m = z * sd / np.sqrt(n)
print(f"95% CI: ({mean-m:.3f}, {mean+m:.3f})")      # (7.010, 7.990)

# ③ 小样本改用 t 分布（σ 未知）
mean, sd, n, conf = 42.24, 3.62, 10, 0.99
t = stats.t.ppf(1 - (1 - conf) / 2, n - 1)         # 3.2498
m = t * sd / np.sqrt(n)
print(f"99% CI: ({mean-m:.3f}, {mean+m:.3f})")      # (38.520, 45.960)

# ④ 比例：Wald（书上）vs Wilson（别用 Wald）
x, n, conf = 55, 100, 0.95
p = x / n
z = stats.norm.ppf(1 - (1 - conf) / 2)
lo, hi = p - z*np.sqrt(p*(1-p)/n), p + z*np.sqrt(p*(1-p)/n)
den = n + z*z                       # Wilson
ctr = (x + z*z/2) / den
half = z/den * np.sqrt(x*(n-x)/n + z*z/4)
print(f"Wald   ({lo:.4f}, {hi:.4f})")     # (0.4525, 0.6475)
print(f"Wilson ({ctr-half:.4f}, {ctr+half:.4f})")
```

## CTA / 量化关联

| 本章结论 | CTA 上的直接后果 |
| :--- | :--- |
| 覆盖率是「程序的长期频率」，不是「这个区间的概率」 | 回测报告写「年化 18% ± 3%（95% CI）」时，**不能**说「真收益有 95% 概率在 15%~21%」；只能说「若重复跑同类回测，95% 的区间会覆盖真值」 |
| 误差范围 ∝ 1/√n | 想把策略收益的估计误差减半，回测窗口要 **×4**（3 年 → 12 年）。这解释了为什么「多测几段行情」比「换更精细的参数」更有效 |
| 「n > 30 就够」要亏约 1 个百分点 | 30 笔交易样本下用 z 而非 t，区间系统性偏窄——**正好往乐观方向偏** |
| t 修 σ、不修形状 | 交易盈亏是极重尾分布，30 笔交易的均值/胜率区间**两种修正都不够**，只有加样本管用 |
| **Wald 在 p 接近 0/1 时会输出越界区间** | 回测报告里「30 笔 27 胜 = 90%，95% CI (79.3%, 100.7%)」是原样抄公式的结果。**胜率这种「小样本 + 高比例」正好是 Wald 的重灾区**，比均值那边危险得多 |
| Wilson 几乎零成本 | 把胜率区间换成 Wilson：「30 笔 27 胜」→ (74.4%, 96.5%)，这才是能拿去决策的区间（下界 74.4% 就是要命的信息） |
| 民调 ±3% 要 1068 个样本 | 想把策略胜率估到 ±3%，需要约 1000 笔交易。这个数字应该写进策略上线标准 |
| 比例最坏情况固定在 p̂ = 0.5 | 规划样本量时直接用 p = 0.5 算，保证够用 |

**被实测打掉的两个直觉**（这两条最有价值）：

1. 我以为 bootstrap 在偏斜数据上会明显优于 t —— **实测完全没有**（n=31：t 88.0% vs bootstrap 88.1%）。百分位 bootstrap 照抄了样本自身的偏度与离散度。
2. 我以为「n > 30 用正态代替 t」只是理论上的不严谨 —— **实测在 n=31 上真金白银地亏 0.93 个百分点**，且要 n≥500 才收敛到 0.1。

## 衔接

第 5 章把「用样本推断总体」的工具箱补齐了：**点估计 → 带不确定性的区间 → 覆盖率的长期保证**。第 6 章会用同一套基础做另一件事：把「某个发现是不是真的」变成可判决的问题——假设检验。本章的临界 Z 值、标准误、t 分布会原封不动地出现在 pp 值和显著性判据里。

也要记住本章留下的边界：**这三节反复撞到同一堵墙——分布形状**。t、bootstrap、Wilson 修的都是「估计量的抽样误差」，修不了「总体本身有多歪」。到了第 9 章（统计陷阱）会看到这堵墙以 p 值滥用、幸存者偏差等形式反复出现。
