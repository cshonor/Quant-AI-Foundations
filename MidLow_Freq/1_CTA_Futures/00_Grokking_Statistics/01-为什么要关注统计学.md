# 第 1 章 · 为什么要关注统计学

## 本章讲什么

回答一个前置问题：统计学对**不同岗位**分别有什么用？以及它和机器学习的关系、它在现实中如何被滥用。

## 要点

### 统计学的价值

把**样本数据转化为可执行洞察**，用于：

- 职业发展、释放数据价值；
- **不确定环境下做决策**；
- 机器学习 / AI 的底层基础。

### 不同岗位如何使用统计

| 岗位 | 用法 |
| :--- | :--- |
| 分析师 | 依靠统计做业务判断 |
| 软件 / 硬件工程师 | A/B 测试、系统稳定性、零件公差 |
| 管理者 | 分辨报告是否存在偏见 |

### 现实痛点：统计被滥用

媒体、职场会出现**结论矛盾的数据报告**，根源来自激励扭曲：

- **p 值操纵**（p-hacking）；
- **挑选有利结果**（cherry-picking）;
- **资金资助带来立场偏向**。

应对方式：用统计素养做批判性核查。

### 统计学 VS 机器学习

| 维度 | 统计学 | 机器学习 |
| :--- | :--- | :--- |
| 侧重 | 解释、可解释性、**量化不确定性** | 预测效果，模型常作黑盒 |
| 关系 | 二者大量技术重叠，实际工作应当**取长补短** | |

### 统计分析标准四流程

1. **提出假设**
2. **收集代表性数据**
3. **拟合模型**
4. **在未见新数据上测试评估**

### Python 要求

掌握基础语法，了解 `numpy`、`pandas`、`matplotlib` 即可。
