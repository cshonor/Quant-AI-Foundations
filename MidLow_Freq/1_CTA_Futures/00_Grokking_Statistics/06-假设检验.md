# 第 6 章 · 假设检验（p 值与显著性）

## 本章讲什么

第 5 章学会了「报一个带不确定性的范围」，这一章回答另一个问题：**这个"发现"是真的吗？**

作者先从历史讲起（Fisher 的女士品茶实验），然后给出一套固定骨架：把想挑战的主张写成**备择假设 Ha**，把现状写成**原假设 H0**，算出样本统计量落进拒绝区的概率（**p 值**），小于显著性水平 α 就拒绝 H0。全书依次展开：双尾检验、单尾检验、小样本 t 检验、比例检验、独立样本检验。

> 本章笔记的数字全部来自可复现实验（见文末「可运行实验」），不是抄书。

## 要点

### 骨架：四个零件

| 零件 | 含义 |
| :--- | :--- |
| **H0（原假设）** | 现状 / 无效应，例如「薯片每袋 142 克」 |
| **Ha（备择假设）** | 想去挑战的主张，例如「不等于 142 克」；二者互斥且互补 |
| **显著性水平 α** | 尾部面积 = 1 − 置信水平；α = 0.05 ⇒ 双尾各分 0.025 |
| **p 值** | **在 H0 为真的前提下**，观察到至少这么极端的样本统计量的概率 |

书上薯片例题（n = 41、x̄ = 140.2、s = 4.79）的完整复现：

```
z = (x̄ − μ) / (s/√n) = −2.4062
双尾临界 = ±norm.ppf(1 − α/2) = ±1.959964
双尾 p   = 2·Φ(−|z|)       = 0.0161   ⇒ 拒绝 H0
95% CI   = (138.7338, 141.6662)       ⇒ 142 落在区间外
```

**CI 与双尾检验是同一枚硬币**：区间排除 μ₀ ⇔ 双尾检验在 α 水平拒绝 H0。作者没明说，但两条路径给出的结论必然一致。

### 女士品茶：p 值在说什么（和不说什么）

Muriel Bristol 声称能分辨先倒奶还是先倒茶，8 杯（4 杯先奶）全部猜对。

| 计算方式 | 结果 |
| :--- | :--- |
| 精确组合数 1/C(8,4) = 1/70 | **1.4286%** |
| 蒙特卡洛 100 万次 | 1.4421%（标准误 ±0.012%） |
| 零假设完整分布 | 猜中 k 杯 ~ 超几何 C(4,k)·C(4,4−k)/70（5 个格子最大偏差 < 1e-3） |

**这是 p 值的定义本身：P(这么极端的结果 | H0)。** 作者紧接着给出警告——它**不是**「H0 为真的概率」。这句警告可以被算成钱：

> 给「世上有人真能分辨倒茶顺序」一个 **0.1%** 的先验，即使把备择假设放到最有利的位置（真有能力就必定全对），八杯全对之后她有能力的后验也只有 **6.5%**。

| 先验 P(有能力) | 八杯全对后的后验 |
| ---: | ---: |
| 0.1% | **6.5%** |
| 1% | 41.4% |
| 10% | 88.6% |
| 50% | 98.6% |

同一个 p = 0.014，配不同的先验能得出完全相反的结论。**p 值回答「数据与原假设不相容的程度」，不回答「哪个假设更可能」**——后者必须显式给出先验（贝叶斯的地盘）。

### p 值不度量效应大小

固定 −1.8 克的偏差，只改样本量：

| n | z | 双尾 p |
| ---: | ---: | ---: |
| 10 | −1.188 | 0.235 |
| 41 | −2.406 | 1.61e−2 |
| 100 | −3.758 | 1.71e−4 |
| 400 | −7.516 | 5.66e−14 |
| 1600 | −15.031 | 4.58e−51 |

效应一个字没动，p 值掉了 50 个数量级。写回测报告时真正值钱的是效应本身（平均日收益）和它的置信区间，p 值只回答「这么大的样本能不能把效应和噪声区分开」。

### σ 未知时该查哪张表（本章最贵的一笔）

**(x̄ − μ)/(s/√n) 的精确分布是 t(n−1)，正态只是它的极限。** 书上薯片例题为了接 CLT 用了正态表，账单如下（各 α 档的真实误报率，解析值 P(|T_df| > z_α)）：

| 自由度 df | α = 0.05 实付 | 相对虚报 |
| ---: | ---: | ---: |
| 5 | 0.0805 | 60.9% |
| 10 | 0.0655 | 31.0% |
| 20 | 0.0578 | 15.6% |
| 40 | 0.0539 | 7.8% |
| 100 | 0.0516 | 3.1% |
| 400 | 0.0504 | 0.8% |

同 df = 20 换成 α = 0.01 ⇒ **实付 1.53%，相对虚报 53%**（阈值压严十倍，相对误差翻 3.4 倍）。这与第 5 章「n = 31 用 z 亏 0.93 个百分点」是同一笔债，只是这次用误报率收。

> 书上那个薯片 z = −2.4062，查正态表 p = 0.0161，查 t(40) 表 **p = 0.0208** —— 都拒绝，但报告里的数字差了 29%。

**「n > 30 就够」不是一条分界线，是一条收敛很慢的尾巴**：要到 df ≈ 400 相对误差才压进 1%。而 t 分布在现代软件里跟正态一样是一行函数调用，**没有任何理由为了省一行代码去虚报**。

### 双尾 vs 单尾：真正的代价在哪

同一份薯片数据改成方向性主张 Ha: μ < 142：

| 版本 | 临界值 | p 值 |
| :--- | :--- | :--- |
| 双尾 | ±1.959964 | 0.0161 |
| 单尾（左） | −1.644854 | **0.0081**（恰好一半） |

作者据此说单尾「更容易拒绝 H0，因此更不保守」。实测把这句话拆成三笔：

1. **在真实的 H0 世界里，三种检验的误报率都是 5%**（6 万次：左 4.91% / 右 5.07% / 双 5.01%）。单尾并没有额外送拒绝——它改变的是**拒绝区的形状**（把 5% 从两个尾部各一半挪到一个尾部全押），不是大小。

2. **真正的代价是另一侧的视力**（解析功效，n = 41、σ = 4.79）：

   | 真实效应 | 左尾 Ha: μ<142 | 双尾 Ha: μ≠142 | 右尾 Ha: μ>142 |
   | :--- | ---: | ---: | ---: |
   | −1.8 克（押对） | **76.43%** | 65.11% | 0.0030% |
   | +1.8 克（押反） | **0.0030%** | 65.11% | 76.43% |

   方向押对时单尾确实高 11.3 个百分点；押反时它几乎瞎掉（0.003%），而同一份数据双尾还有 65%。

3. **看完数据再挑尾巴 → 名义 5% 当场变 10%。** 规则是「双尾不显著就按观测方向改单尾」，等价于拒绝域变成 |T| > t₀.₉₅ ⇒ P(|T₄₀| > t₀.₉₅) = **0.1000**（实测 9.86%）。而且可被这套话术翻盘的样本占真 H0 世界的 **4.96%** —— 与 α 等宽，不是巧合。

> ⇒ 一个「什么都没发生」的世界里，每 20 次尝试就约有 1 次能被包装成发现。这是第 9 章 p-hacking 的最小工作原理。

### 比例检验：作者偷偷换了个更好的公式

作者在两处用了不同的标准误，全书没有点破这处不一致：第 5 章的置信区间用 **p̂** 估标准误（Wald），第 6 章的检验改用 **p₀** 估标准误（score）。全书没有点破这处不一致，但改对了——实测三种场景在 H0 下的双尾误报率（名义 5%）：

| 场景 | score（第 6 章） | Wald（第 5 章） | 精确二项 |
| :--- | ---: | ---: | ---: |
| p₀ = 0.65, n = 45 | **4.21%** | 6.70% | 4.11% |
| p₀ = 0.05, n = 100（np = 5 边界） | **3.39%** | **11.56%** | 3.41% |
| p₀ = 0.50, n = 30（回测常见形态） | 4.36% | 4.36% | 4.28% |

Wald 版在最需要保护的边界上虚报一倍多。**根子是那个熟悉的耦合：同一个估计量既当位置又当尺度** —— p̂ 越靠近 0/1，它当尺度时越不可靠（与第 5 章 Wald 区间 Coverage 崩掉是同一个机制）。顺带一个通用的教训：**估计视角和检验视角的最优公式未必是同一个**。

### 独立样本：什么时候必须用 Welch

书上两个班级的例子（83/11.2/37 与 75/10.9/35）得 z = 3.0713、p = 0.0011。但这里的隐藏条件是**两个总体的方差**：

| 条件 | 书上的 z 版 | Welch t |
| :--- | ---: | ---: |
| 方差齐、样本量接近（σ 都 = 10，n = 37/35） | 5.50% | 5.15%（df ≈ 68） |
| **方差 1:3 且样本量悬殊**（σ = 6/18，n = 40/12） | **7.40%** | 4.45%（df ≈ 12） |

坑的形态很稳定：**方差不齐本身不可怕，可怕的是方差不齐叠上样本量悬殊**。作者用一行注释带过了它的代价（「t 分布通常是应对两个样本方差是否不同这一不确定性的首选工具」）。

## CTA / 量化关联

| 本章结论 | CTA 上的直接后果 |
| :--- | :--- |
| p 值是「H0 下看到这么极端的概率」，不是「H0 为真的概率」 | 「策略收益显著为正，p = 0.03」**不等于**「策略 97% 概率会赚钱」。后者需要一个先验（同类策略的先验成功率），而那个先验通常很悲观 |
| p 值不度量效应大小 | 「日收益 0.02%、n = 1096、p = 0.02」── 显著，但扣掉 10bp 费率后还剩什么，才是要回答的问题 |
| σ 未知时该查 t 表；样本越小、α 越严，z 版的虚报比例越高 | 30 笔交易上用 z 版宣布 α = 1% 的发现，实际门槛只有 1.5%。**做高置信决策时必须用 t（或 Welch）** |
| 事后挑尾巴 = 误报率翻倍 | 网格搜 30 组参数后宣布「我本来就只关心正向收益」，这是把 5% 买到 10%+ 的同一套动作。方向必须在看到数据之前写在纸上 |
| 单尾押反方向 ⇒ 灵敏度 0.003% | 声明「只关心这个止损会不会放大回撤」时，它对「回撤变小但收益也被打死」是盲的 |
| 方差不齐 + 样本悬殊时 z 版虚报到 7.4% | 比较「有信号的那 40 天」和「没有信号的几百天」的收益，天然就是这种配置 ⇒ 默认用 Welch |
| 比例检验用 score/Wilson 而不是 Wald | 「30 笔 27 胜 = 90% 胜率」做假设检验时同样别用 p̂ 估标准误 |

## 可运行实验（math-lab）

配套代码在 `math-lab/grokking-statistics/ch06-假设检验/`，**3 节 / 20 个判定项全部 PASS**。

| 小节 | 判决的命题 | 实测结论 |
| :--- | :--- | :--- |
| `6.1-p值到底是什么：女士品茶与双尾检验.py` | 1/70 是否收敛 / 复现薯片 / t 版 vs z 版 p 值是否均匀 / p 值是不是后验 / p 是否与效应无关 | 蒙特卡洛 100 万次 = 1.4421%（精确 1.4286%）；**t 版 P(p≤0.05)=0.0502，z 版 0.0577（α=0.01 时 1.33%，虚报 33%）**；先验 0.1% 时后验仅 6.5%；同样效应下 p 从 0.235 掉到 4.6e−51 |
| `6.2-单尾检验：更不保守这笔账怎么算.py` | 复现单尾数字 / H0 下三者是否都是 5% / 单尾的真实代价 / 事后挑尾的价格 | 单尾 p = 0.0081（双尾的一半）；H0 下三者都是 5%；押反方向 power **0.003% vs 65.11%**；押对 **76.43% vs 65.11%**；事后挑尾 **9.86%（解析 10%）**，可翻盘样本 **4.96%** |
| `6.3-小样本比例与两样本：n>30的账单.py` | 复现三道例题 / z 版账单随 df 的收敛 / score vs Wald / Welch 何时必要 | 三题 p 值全部复现（0.0711 / 0.0174 / 0.0011）；**df=20 且 α=0.01 实付 1.53%（虚报 53%）**；p₀=0.05/n=100 上 score 3.39% vs Wald **11.56%**；方差 1:3 + 样本悬殊时 z 版 **7.40%** vs Welch 4.45% |

**被实测纠正的直觉**（这三条最有价值）：

1. 我以为「单尾更容易拒绝 H0」意味着它在 H0 下也会多拒绝 —— **实测不成立**：三种检验的误报率都是 5%。单尾改的是拒绝区的**位置**，赚到的东西要到「真有效应且方向对了」那一步才兑现。
2. 我以为 p 值均匀分布是定义自带的，跟查哪张表无关 —— **实测不成立**：统计量一字未改，只把最后一步从 t(40) 换成正态，α=0.05 就实付 5.77%，α=0.01 实付 1.33%。
3. 我以为作者在两个比例场景用了同一套公式 —— **实测发现他换了**（CI 用 Wald、检验用 score），而且换对了：边界上 3.39% vs 11.56%。教材里这种「没说出来的改进」通常比正文更值得抄。

## 衔接

第 6 章把「某个发现是不是真的」变成了可判决的问题。它留下的边界有两条：

- **单次的显著不等于可重复** —— 本章只讲了单个检验的行为（p 值均匀、误报率 = α）；一旦同时跑很多个检验，这套保证会整体失效，这是第 9 章多重比较 / p-hacking 的主战场；
- **本章全部假设总体本身是正态（或样本够大）** —— 第 7 章会把同样的数据结构从「比较两个均值」推广到「两个变量如何一起动」（相关性）和「用一个变量解释另一个」（回归），届时残差的正态性会成为新的前提条件。
