# 第 4 章 · 正态性的宏大展览（正态分布与中心极限定理）

## 本章讲什么

正态分布的形状与参数、**密度不等于概率**、经验法则与切比雪夫定理、中心极限定理（CLT）、Z 分数与标准正态分布、以及对数正态分布。本章是全书的转折点——从这里开始，统计学能真正用于「从样本推断总体」。

> 本章笔记的数字全部来自可复现实验（见文末「可运行实验」），不是抄书。

## 要点

### 正态分布的特性

- 由 **均值 μ**（位置）和 **标准差 σ**（宽窄）完全决定；曲线下面积恒为 1.0。
- 对称、单峰，中心即均值；向尾部趋近于 y=0 但**永不触及 0**。
- σ 越小 ⇒ 越集中 ⇒ 可预测性越高。

| 常见误解 | 正确说法 |
| :--- | :--- |
| 「x = 61.63 磅的概率是 0.0973」 | 0.0973 是**概率密度**（pdf），单点概率恒为 **0** |
| 「概率 = 曲线高度」 | 概率 = **区间下面积**，用 CDF 相减求 |

**实测**（金毛寻回犬 N(64, 3²)）：把区间宽度 h 从 1 缩到 0.005，P/h 收敛到 0.0973，收敛阶 0.99 —— 密度就是「单位宽度的概率」。区间 P(61 ≤ X ≤ 63) = 0.2108，与书上一致。

### 经验法则（只适用于正态数据）

| 范围 | 精确值 | 口头版 |
| :--- | :--- | :--- |
| μ ± 1σ | **68.27%** | 68% |
| μ ± 2σ | **95.45%** | 95% |
| μ ± 3σ | **99.73%** | 99.7% |

实测：换成 N(1000, 137²) 后三个比例完全不变（差 0.00e+00）——与 μ、σ 取值无关，这是它能当「经验」用的前提。

### 切比雪夫定理（适用于任意分布）

落在 μ ± kσ（k > 1）内的比例 **至少** 1 − 1/k²。

**实测的松紧程度**（真实右偏的龙卷风宽度，偏度 3.30）：

| k | 下界 | 龙卷风实测 | 正态实际 |
| :--- | :--- | :--- | :--- |
| ±1.5σ | 55.56% | 92.37% | 86.64% |
| ±2σ | 75.00% | 94.83% | 95.45% |
| ±3σ | 88.89% | 97.32% | 99.73% |
| ±4σ | 93.75% | 98.57% | 99.99% |

下界确实成立（说「至少」没吹牛），但真正离谱的是**尾部**：±3σ 之外它允许 11.11%，正态真实只有 0.27%（放大 **41 倍**）；±4σ 之外放大近 **1000 倍**。⇒ 它是「最坏情况声明」，不是估计值，拿它计提风险等于把尾部放大几十到上千倍。

### 中心极限定理（CLT）

1. 样本均值的均值 → 总体均值；
2. 样本均值的标准差（标准误）= **σ/√n**；
3. 总体正态 ⇒ 任意 n 下样本均值都正态；
4. 总体**任意分布** ⇒ n「足够大」时样本均值近似正态（书上说 31，但作者自己也说「有例外，很多从业者认为教科书这个说法有问题」）。

**实测（龙卷风宽度，n=3210，偏度 3.30，超额峰度 14.30，M=4000 批）**：

| n | 残余偏度 | 理论 γ₁/√n | 右尾 2σ 实测 | 正态 2.28% |
| :--- | :--- | :--- | :--- | :--- |
| 5 | 1.418 | 1.475 | — | — |
| 31 | **0.566** | 0.592 | **3.88%** | 2.28% |
| 250 | 0.213 | 0.209 | — | — |
| 500 | 0.109 | 0.147 | 2.15% | 2.28% |

- 均值与标准误这两条，**n=5 就成立**（标准误相对误差 ≤ 4%，n≥15 时 < 3%）；
- 形状按 √n 收敛（拟合斜率 **−0.54**，理论 −0.5）；
- **n=31 时右尾被正态低估 70%**（3.88% vs 2.28%），左右尾频率差 **6.7 倍**——正态模型给不出这种不对称。

⇒ **「31 够不够」取决于用途**：估计均值 / 给 ±2σ 区间，31 够；算尾部风险（止损、风险预算），31 远远不够。

### Z 分数与标准正态分布

z = (x − μ) / σ，把任意正态换成 N(0, 1)。书例：40 克咖啡 = (40 − 27.6)/3.2 = **3.875σ**，超出 3σ（99.7%）圈子 ⇒ 判为异常值。

### 对数正态分布

右偏数据取对数后呈钟形 ⇒ 可用正态工具。**实测**：龙卷风宽度 log10 后偏度从 3.297 降到 **−0.185**，均值 2.0056 / 中位数 2.0 几乎重合；同样 n=31，尾部近似误差从 **+70%** 降到 **−2.2%**。

代价：结论要换尺度解释——log 尺度的均值取 10 的幂回去是**几何均值**，不是算术均值。

## 代码示例

```python
import numpy as np
from scipy import stats

# 密度 vs 概率：0.0973 是密度，不是概率
print(stats.norm.pdf(61.63, 64, 3))                       # 0.0973（密度，量纲 1/磅）
print(stats.norm.cdf(63, 64, 3) - stats.norm.cdf(61, 64, 3))  # 0.2108（概率：区间面积）

# 经验法则的精确值
for k in (1, 2, 3):
    print(k, stats.norm.cdf(k) - stats.norm.cdf(-k))      # 0.6827 / 0.9545 / 0.9973

# 切比雪夫：任意分布下 ±kσ 内至少 1 - 1/k²
k = 3.0
print(1 - 1 / k**2)                                       # 0.8889

# CLT：从右偏总体里抽 m 批、每批 n 个，看样本均值的分布
pop = np.random.lognormal(0, 1.2, size=100_000)           # 替身：真实数据见文末
for n in (31, 500):
    means = pop[np.random.randint(0, len(pop), (4000, n))].mean(axis=1)
    print(n, "SE", means.std(ddof=1), "理论", pop.std(ddof=1) / np.sqrt(n),
          "偏度", stats.skew(means))

# 尾部：正态模型 vs 实测（BTCUSDT 日收益，n=1998）
z = (r - r.mean()) / r.std(ddof=1)
for k in (3, 4, 5):
    print(k, np.mean(np.abs(z) > k), 2 * stats.norm.sf(k))
```

## CTA / 量化关联

| 本章概念 | 在 CTA 里对应什么 | 实测给的警告 |
| :--- | :--- | :--- |
| 密度 ≠ 概率 | 别用 pdf 值当触发阈值 | pdf 量纲是 1/单位，σ 变小它会无限变大 |
| 经验法则 ±2/±3σ | 用「几个 σ」判定异常、设熔断 | 真实日收益超额峰度 4.01，4σ 以上实测 9 次 vs 正态预测 0.13 次 |
| 切比雪夫 | 分布未知时的保底风控 | 尾部放大 41×（3σ）到 987×（4σ），只能当最坏情况 |
| CLT / 标准误 | 用 N 笔交易估「策略真实日均收益」 | 均值估计 n=31 够用，尾部估计不够：右尾低估 70% |
| 对数正态 | 右偏的价格/成交量/资金曲线 | 取对数后 n=31 的尾部误差从 +70% 降到 −2.2% |

**正态 VaR 的误差方向会翻转**（BTCUSDT 日收益 n=1998）：95% VaR 经验 −4.52% vs 正态 −4.72%（正态**偏保守** 4.4%）；99% VaR 经验 −8.24% vs 正态 −6.68%（正态**偏乐观** 18.9%）。⇒「正态 VaR 保守一点」只在中等分位成立，极端分位上它低估风险。

书里那个「25 个标准差」的笑话可以量化：P(|Z| > 25) = 6.11e−138。出现这种量级的偏离时，正确动作是**改模型**，不是给运气找借口。
