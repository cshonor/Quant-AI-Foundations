# 9.B 实内积空间上的算子

## 核心知识点与关键定义

- **实正规算子**：TT\* = T\*T。
- **二维非自伴正规**：T 正规非自伴 ⟺ 某规范正交基下矩阵 [[a, −b], [b, a]]，b > 0。
- **正交补不变性**：U 为 T-不变且 T 正规 ⟹ U<sup>⊥</sup> 也 T-不变。

## 重点结论与公式要点

- T 正规，U 不变 ⟹：
  1. U<sup>⊥</sup> 不变；
  2. U 在 T\* 下不变；
  3. (T|_U)\* = (T\*)\|_U；
  4. T|_U、T|_{U<sup>⊥</sup>} 仍正规。
- **实正规算子刻画**：存在规范正交基使 M(T) **分块对角**，块为 1×1（实本征值）或 [[a, −b], [b, a]]（b > 0）。
- **实等距同构**：S 等距 ⟺ 规范正交基下分块对角，块为 [1]、[-1] 或旋转矩阵 [[cos θ, −sin θ], [sin θ, cos θ]]（θ ∈ (0, π)）。

## 案例数据与易错细节

- **案例**：**R**<sup>2</sup> 旋转 θ（θ 非 π 整数倍）无实本征值，但是完美等距同构。
- **易错**：实正规算子**不能**保证纯对角化；极致形式是 1×1 + 2×2 分块。
- **易错**：U 不变 ⟹ U<sup>⊥</sup> 不变**仅**在 T 正规时成立。

## 逻辑脉络与关联推演

- 9.A 的一维/二维不变子空间 + 正交补不变 → 归纳剥离 1×1 与 2×2 块 → 实正规与实等距的完整结构。

## 预留拓展空间

- O(n)、SO(n)；欧拉旋转定理与奇数维等距必含 ±1 块或旋转块的联系。
