# 2.A 张成空间与线性无关

> **前置**：向量空间、子空间（1.A–1.C）  
> **后续**：基与维数（2.B）——本节为「基」奠基

---

## 一、张成空间（Span）

### 1. 定义

设 V 是 **F** 上向量空间，v<sub>1</sub>, …, v<sub>m</sub> ∈ V。该组的**张成空间**为

span(v<sub>1</sub>, …, v<sub>m</sub>) = { λ<sub>1</sub>v<sub>1</sub> + … + λ<sub>m</sub>v<sub>m</sub> | λ<sub>1</sub>, …, λ<sub>m</sub> ∈ **F** }

即一切**线性组合**的全体。空组规定：span(∅) = {**0**}（仅含零向量）。

### 2. 核心性质

| 性质 | 要点 | 通俗 |
| :--- | :--- | :--- |
| **是子空间** | 非空（全系数取 0）、加法/数乘封闭 | 怎么线性混合都在同一闭合集合里 |
| **最小包容** | 含 v<sub>1</sub>, …, v<sub>m</sub>；任何包含该组的子空间 W 必含 span | 「刚好装下这组向量」的最小线性空间 |
| **任意子集 S** | span(S) = S 中有限个向量的一切线性组合 | 有限/无限 S 均可定义 |

**例**：**R**<sup>3</sup> 中 span{(1,0,0), (0,1,0)} = xy 平面；span{(1,1,1)} = 过原点的一条直线。

### 3. 张成全空间

若 span(v<sub>1</sub>, …, v<sub>m</sub>) = V，称 {v<sub>1</sub>, …, v<sub>m</sub>} **张成** V——能组合出 V 中任意向量。

**关键**：张成**不要求**线性无关。相关组、含零向量、重复向量均可谈张成；张成只问「能组合出什么」，不问「有无冗余」。

**例**：**R**<sup>3</sup> 中 a = (1,0,0), b = (2,0,0) 线性相关，但 span(a, b) = x 轴仍成立。

---

## 二、线性无关

### 1. 定义

v<sub>1</sub>, …, v<sub>m</sub> **线性无关** ⟺ 方程

λ<sub>1</sub>v<sub>1</sub> + … + λ<sub>m</sub>v<sub>m</sub> = **0**

**仅有零解** λ<sub>1</sub> = … = λ<sub>m</sub> = 0。

### 2. 等价理解

- 组内**没有任何一个**向量可写成其余向量的线性组合；  
- 向量彼此独立，**零冗余**。

---

## 三、线性相关

### 1. 定义与等价

**线性相关** ⟺ 存在**不全为 0** 的 λ<sub>1</sub>, …, λ<sub>m</sub> ∈ **F**，使 λ<sub>1</sub>v<sub>1</sub> + … + λ<sub>m</sub>v<sub>m</sub> = **0**。

⟺ 组内**至少有一个**向量可被其余向量线性表示。

### 2. 特殊情形（快速判定）

| 情形 | 结论 |
| :--- | :--- |
| **单个向量** {v} | 无关 ⟺ v ≠ **0**；相关 ⟺ v = **0** |
| **两个向量** u, v | 相关 ⟺ **成比例**（u = kv, k ∈ **F**）；无关 ⟺ 不成比例 |
| **空向量组** ∅ | 规定**线性无关**；span(∅) = {**0**} |

### 3. 四条基础结论（含证明要点）

**① 含零向量 → 必相关**  
若 v<sub>1</sub> = **0**，取 λ<sub>1</sub> = 1，其余 λ<sub>i</sub> = 0，得非全零系数组合为 **0**。

**② 无关组的任意子集 → 仍无关**（**向下传递**）  
逆否：子集相关 ⇒ 补 0 系数后全集相关。

**③ 相关组的任意超集 → 仍相关**（**向上传递**）  
原相关关系保留；新增向量系数取 0 即可。

**④ n 维空间中向量个数 > n → 必相关**  
齐次方程 A<sub>n×m</sub>**x** = **0**，m > n ⇒ 未知数多于方程 ⇒ 必有非零解。

> ⚠️ 反过来**不成立**：个数 ≤ n **不能**推出无关（见第六节误区）。

### 4. 考场口诀

1. 有零必相关  
2. 无关子集仍无关  
3. 相关超集仍相关  
4. 个数超维必相关

## 四、三大概念横向对比

| 概念 | 核心作用 | 有无冗余 | 向量组要求 | 关键特征 |
| :--- | :--- | :---: | :--- | :--- |
| **张成空间** span | 描述向量能**覆盖的范围** | 允许大量冗余 | 无要求（相关/无关、含零、重复均可） | 只看「能组合出什么」 |
| **线性无关** | 描述向量**彼此独立** | 零冗余 | 组合为 **0** 仅当系数全 0 | 任一向量不可被其余表示 |
| **线性相关** | 描述向量**存在依赖** | 必有冗余 | 存在非零系数使组合为 **0** | 至少一个可被其余表示 |

**关系总结**

1. 线性无关组：删掉**任意**向量 → 张成空间**变小**；  
2. 线性相关组：至少能删掉一个向量 → 张成空间**不变**；  
3. **基** = 线性无关 + 张成全空间（无冗余、刚好覆盖整个空间）。

---

## 五、核心定理（证明 + 解读）

### 1. 线性相关引理

**命题**：若 v<sub>1</sub>, …, v<sub>m</sub> 线性相关，则存在 j ∈ {2, …, m}，使得

1. v<sub>j</sub> ∈ span(v<sub>1</sub>, …, v<sub>j−1</sub>)  
2. span(v<sub>1</sub>, …, v<sub>m</sub>) = span(v<sub>1</sub>, …, v<sub>j−1</sub>, v<sub>j+1</sub>, …, v<sub>m</sub>)

**证明**

因线性相关，存在不全为 0 的 λ<sub>1</sub>, …, λ<sub>m</sub>，使 λ<sub>1</sub>v<sub>1</sub> + … + λ<sub>m</sub>v<sub>m</sub> = **0**。

取**最大**下标 j 使 λ<sub>j</sub> ≠ 0（必有 j ≥ 2；若 j = 1 则 v<sub>1</sub> = **0**，结论仍成立）。

移项得

v<sub>j</sub> = −(λ<sub>1</sub>/λ<sub>j</sub>)v<sub>1</sub> − … − (λ<sub>j−1</sub>/λ<sub>j</sub>)v<sub>j−1</sub>

故 v<sub>j</sub> ∈ span(v<sub>1</sub>, …, v<sub>j−1</sub>)。

**张成相等**：删 v<sub>j</sub> 后 span 显然 ⊆ 原 span；又 v<sub>j</sub> 可由其余向量表出，原 span 中任意组合可消去 v<sub>j</sub>，反向包含成立。∎

**解读**：相关组里必有「可被前面向量表出」的冗余向量；删掉它**不损失**张成能力——与高斯消元「向后删冗余」同构。

---

### 2. 长度不等式（核心定理）

**定理**：设 V 可由 m 个向量张成，则 V 中任意一组**线性无关**向量，所含个数 **≤ m**。

> **通俗**：无关向量的数量，不可能超过张成组的向量数量。

**证明思路**（反复用线性相关引理）

设 A = {u<sub>1</sub>, …, u<sub>k</sub>} 线性无关，B = {v<sub>1</sub>, …, v<sub>m</sub>} 张成 V。

1. 将 u<sub>1</sub> 并入 B，得 {u<sub>1</sub>, v<sub>1</sub>, …, v<sub>m</sub>}（m + 1 个向量），仍张成 V；  
2. 由引理，某个 v<sub>j</sub> 可被前面向量表出，删掉 v<sub>j</sub>，新集合仍张成 V；  
3. 依次并入 u<sub>2</sub>, …, u<sub>k</sub>，每步从原张成组删一个向量；  
4. 最多删 m 个，故 k ≤ m。∎

**推论**

1. n 维空间中，线性无关向量组个数**最多为 n**；  
2. 若一组向量既线性无关、又能张成空间，则向量个数**唯一确定**——这就是**基**（下一节）。

## 六、易混误区

| 误区 | 纠正 |
| :--- | :--- |
| ❌ 个数 ≤ 空间维数 ⇒ 一定无关 | **R**<sup>3</sup> 中 (1,0,0), (2,0,0) 共 2 个 < 3，但**相关** |
| ❌ 张成空间相等 ⇔ 向量组无关 | span(1,0,0) = span(1,0,0, 2,0,0)，张成相同，后者**相关** |
| ❌ 无关组添加向量后仍无关 | **不向上传递**：{(1,0),(0,1)} 无关，加 (2,0) 后**相关**；加 (1,1) 仍无关 |

**传递性口诀**

- 无关组的**子集** → 仍无关（向下）  
- 相关组的**超集** → 仍相关（向上）  
- 含零向量 → 必相关  
- 个数 **> 空间维数** → 必相关

## 七、典型例题

### 例 1 判定线性相关/无关

**R**<sup>3</sup> 中 **a** = (1,2,3)，**b** = (2,4,6)，**c** = (1,0,1)。

**b** = 2**a** ⇒ {**a**, **b**} 相关 ⇒ 由「相关超集仍相关」，{**a**, **b**, **c**} **线性相关**。

### 例 2 张成空间判断

V = **R**<sup>2</sup>，向量组 {(1,1), (2,2)}。

两向量成比例 ⇒ 相关；span = {k(1,1) | k ∈ **R**} 是一条直线，**不能张成 R**<sup>2</sup>。

### 例 3 结合长度不等式

**R**<sup>4</sup>（4 维），下列说法：

| 选项 | 判断 | 理由 |
| :---: | :---: | :--- |
| A. 任意 5 个向量必相关 | ✅ | 5 > 4 |
| B. 任意 3 个向量必无关 | ❌ | 个数 ≤ 维数不能推出无关 |
| C. 4 个无关向量一定能张成 **R**<sup>4</sup> | ✅ | 无关组长度 = 维数 ⇒ 是基（下一节） |

### 例 4 线性组合归属（**F**<sup>3</sup>）

(17, −4, 2) **是** (2, 1, −3) 与 (1, −2, 4) 的线性组合；(17, −4, 5) **不是**——解方程组或算秩即可验证。

### 例 5 有限维 vs 无限维

P<sub>m</sub>(**F**)（次数 ≤ m 的多项式）**有限维**；P(**F**)（全体多项式）**无限维**——后者无法由有限个向量张成。

## 八、解题通用步骤

### 题型 1：判断线性相关/无关

1. 向量写成列向量，构造齐次方程 A**x** = **0**；  
2. 求秩 / 行列式 / 自由未知量：  
   - 只有零解 ⇒ **无关**；  
   - 存在非零解 ⇒ **相关**。  

**快捷路径**：先看含零、成比例、个数 > 维数；再用方程组兜底。

### 题型 2：判断能否张成空间

1. 求该组 span 的维数（或化为行最简形看秩）；  
2. 若 span 维数 = 原空间维数 ⇒ **可以张成**；否则不能。

### 题型 3：证明题（引理 / 长度不等式）

- 相关 ⇒ 找最大下标非零系数 → 表出 v<sub>j</sub> → 证 span 不变；  
- 长度不等式 ⇒ 逐步并入无关向量 + 引理删冗余。

---

## 九、知识链路（前后章串联）

```
向量空间 → 子空间 → 张成空间（构造子空间的通用方法）
                    ↓
              线性相关 / 无关（判断冗余）
                    ↓
        线性相关引理 + 长度不等式
                    ↓
              基 与 维数（2.B）
```

**整体逻辑**：先用线性组合造出空间 → 用相关性剔除多余向量 → 得到最简表达（基）。

**其他关联**

- span(v<sub>1</sub>, …, v<sub>m</sub>) 是包含该组向量的**最小子空间**；  
- 有限维空间的子空间必为有限维（由长度不等式推出）；  
- 零多项式次数取 −∞，以保持 deg(pq) = deg p + deg q（多项式空间语境）。

## 一句话区分

- **张成**：只看能否组合出目标，相关无关都可以。  
- **基**：必须线性无关，同时还能张成目标空间。
