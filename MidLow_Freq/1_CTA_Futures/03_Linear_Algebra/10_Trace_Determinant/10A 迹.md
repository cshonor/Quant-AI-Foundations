# 10.A 迹

## 核心知识点与关键定义

- **单位矩阵 I**：对角线为 1，其余为 0。
- **可逆矩阵 A<sup>−1</sup>**：AB = BA = I。
- **算子的迹 trace T**：
  - **C** 上：T 的按重数重复的本征值之和；
  - **R** 上：T<sub>C</sub> 的按重数重复的本征值之和。
- **矩阵的迹 trace A**：对角线元素之和。

## 重点结论与公式要点

- **基变换**：M(T, (u)) = A<sup>−1</sup> M(T, (v)) A，A = M(I, (u), (v))。
- trace T = 特征多项式中 z<sup>n−1</sup> 系数的**相反数**（n = dim V）。
- trace(AB) = trace(BA)；trace T **不依赖基**；trace T = trace M(T)。
- trace(S + T) = trace S + trace T。
- **不存在** ST − TS = I（有限维）：trace(ST − TS) = 0，但 trace I = dim V ≠ 0。

## 案例数据与易错细节

- **案例**：**C**<sup>5</sup> 上已知 M(T)，trace T = 对角线之和 = 本征值之和，不必解五次特征方程。
- **易错**：基变换中 A 与 A<sup>−1</sup> 顺序不可颠倒；trace(AB) = trace(BA) ≠ AB = BA。
- **关窍**：Axler 先以本征值之和定义 trace（内蕴），再证 = 矩阵对角线之和。

## 逻辑脉络与关联推演

- 相似变换 A<sup>−1</sup>MA → 本征值之和定义 trace → trace(AB)=trace(BA) 消去 A, A<sup>−1</sup> → 对角线之和 = 本征值之和。
