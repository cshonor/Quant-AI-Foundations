# 6.A 内积与范数

## 核心知识点与关键定义

- **点积**：**R**<sup>n</sup> 中 x · y = x<sub>1</sub>y<sub>1</sub> + … + x<sub>n</sub>y<sub>n</sub>。
- **内积**：⟨u, v⟩ ∈ **F** 满足：正性 ⟨v, v⟩ ≥ 0；定性 ⟨v, v⟩ = 0 ⟺ v = 0；第一 slot 加性、齐性；**共轭对称** ⟨u, v⟩ = ⟨v, u⟩̄。
- **内积空间**：带内积的向量空间。
- **范数**：‖v‖ = √⟨v, v⟩。
- **正交**：⟨u, v⟩ = 0。

## 重点结论与公式要点

- ⟨0, u⟩ = ⟨u, 0⟩ = 0；第二 slot 齐性：⟨u, λv⟩ = λ̄⟨u, v⟩。
- **勾股定理**：u ⊥ v ⟹ ‖u + v‖<sup>2</sup> = ‖u‖<sup>2</sup> + ‖v‖<sup>2</sup>。
- **正交分解**：v ≠ 0 时 u = cv + w，c = ⟨u, v⟩/‖v‖<sup>2</sup>，w ⊥ v，分解唯一。
- **柯西-施瓦茨**：|⟨u, v⟩| ≤ ‖u‖‖v‖；等号 ⟺ u, v 之一为另一的标量倍。
- **三角不等式**：‖u + v‖ ≤ ‖u‖ + ‖v‖。
- **平行四边形**：‖u + v‖<sup>2</sup> + ‖u − v‖<sup>2</sup> = 2(‖u‖<sup>2</sup> + ‖v‖<sup>2</sup>)。

## 案例数据与易错细节

- **案例**：**F**<sup>n</sup> 欧几里得内积 ⟨w, z⟩ = w<sub>1</sub>z̄<sub>1</sub> + … + w<sub>n</sub>z̄<sub>n</sub>；P<sub>2</sub>(**R**) 上 ⟨f, g⟩ = ∫<sub>−1</sub><sup>1</sup> f(x)g(x) dx。
- **易错**：复内积第二 slot 须取**共轭**：⟨u, λv⟩ = λ̄⟨u, v⟩。
- **易错**：常先处理 ‖v‖<sup>2</sup> = ⟨v, v⟩，再开方。

## 逻辑脉络与关联推演

- 从 **R**<sup>n</sup> 点积抽象五条公理 → 范数与正交 → 正交分解 → CS 不等式 → 三角不等式与平行四边形。
