# 6.B 规范正交基

## 核心知识点与关键定义

- **规范正交组**：‖e<sub>j</sub>‖ = 1 且 e<sub>j</sub> 两两正交；⟨e<sub>j</sub>, e<sub>k</sub>⟩ = δ<sub>jk</sub>。
- **规范正交基**：由规范正交向量构成的基。
- **线性泛函**：V → **F** 的线性映射。

## 重点结论与公式要点

- ‖a<sub>1</sub>e<sub>1</sub> + … + a<sub>m</sub>e<sub>m</sub>‖<sup>2</sup> = |a<sub>1</sub>|<sup>2</sup> + … + |a<sub>m</sub>|<sup>2</sup> ⟹ 规范正交组**线性无关**。
- 规范正交基下：v = ⟨v, e<sub>1</sub>⟩e<sub>1</sub> + … + ⟨v, e<sub>n</sub>⟩e<sub>n</sub>。
- **格拉姆-施密特**：v<sub>1</sub>, …, v<sub>m</sub> 无关 → 规范正交 e<sub>1</sub>, …, e<sub>m</sub>（每步减去投影后**除以范数**）。
- 有限维内积空间必有规范正交基；规范正交组可扩充为规范正交基。
- **舒尔定理**：复有限维 T 存在规范正交基使 M(T) 上三角。
- **里斯表示定理**：有限维内积空间上，每个线性泛函 φ 唯一对应 u ∈ V 使 φ(v) = ⟨v, u⟩。

## 案例数据与易错细节

- **案例**：对 P<sub>2</sub>(**R**) 的 1, x, x<sup>2</sup> 做 G-S → 勒让德多项式（正规化）。
- **易错**：G-S 每步须**正规化**；仅正交不规范则后续公式不可用。
- **易错**：里斯表示在无限维需完备性（希尔伯特空间）；有限维无条件成立。

## 逻辑脉络与关联推演

- 规范正交基 → G-S 存在性 → 改进三角化（舒尔）与对偶（里斯）。

## 预留拓展空间

- Modified Gram-Schmidt 的数值稳定性。
