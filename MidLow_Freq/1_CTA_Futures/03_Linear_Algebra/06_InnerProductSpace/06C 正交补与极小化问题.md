# 6.C 正交补与极小化问题

## 核心知识点与关键定义

- **正交补 U<sup>⊥</sup>**：U<sup>⊥</sup> = {v ∈ V : ⟨v, u⟩ = 0 对所有 u ∈ U}。
- **正交投影 P<sub>U</sub>**：若 V = U ⊕ U<sup>⊥</sup>，v = u + w（u ∈ U, w ∈ U<sup>⊥</sup>）时 P<sub>U</sub>v = u。

## 重点结论与公式要点

- U 有限维 ⟹ **V = U ⊕ U<sup>⊥</sup>**。
- dim U<sup>⊥</sup> = dim V − dim U；(U<sup>⊥</sup>)<sup>⊥</sup> = U（U 有限维）。
- P<sub>U</sub><sup>2</sup> = P<sub>U</sub>；range P<sub>U</sub> = U，null P<sub>U</sub> = U<sup>⊥</sup>；‖P<sub>U</sub>v‖ ≤ ‖v‖。
- **投影公式**（e<sub>1</sub>, …, e<sub>m</sub> 为 U 的规范正交基）：
  P<sub>U</sub>v = ⟨v, e<sub>1</sub>⟩e<sub>1</sub> + … + ⟨v, e<sub>m</sub>⟩e<sub>m</sub>。
- **极小化**：u ∈ U 时 ‖v − P<sub>U</sub>v‖ ≤ ‖v − u‖；等号 ⟺ u = P<sub>U</sub>v（U 中距 v 最近点）。

## 案例数据与易错细节

- **案例**：在 [−π, π] 上用 ≤5 次多项式最佳逼近 sin x（平方误差极小），优于泰勒展开。
- **易错**：投影公式中的 e<sub>k</sub> 必须是 **U 的规范正交基**，不能用 U 的任意基。
- **易错**：V = U ⊕ U<sup>⊥</sup> 与 (U<sup>⊥</sup>)<sup>⊥</sup> = U 依赖 U **有限维**；无限维非闭子空间可能不成立。

## 逻辑脉络与关联推演

- 正交补 → 直和分解 → 正交投影 → 最短距离/最佳逼近 → 连接最小二乘、傅里叶级数等应用。

## 预留拓展空间

- 最小二乘：Ax ≈ b 时 min ‖Ax − b‖ 的正规方程与投影解释。
