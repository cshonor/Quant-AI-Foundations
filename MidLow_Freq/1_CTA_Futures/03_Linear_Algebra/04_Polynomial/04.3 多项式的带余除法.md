# 4.3 多项式的带余除法

## 核心知识点与关键定义

- **带余除法**：多项式环上的除法结构（类似整数除法）。
- **零多项式次数**：恒为 0 的多项式次数规定为 −∞。

## 重点结论与公式要点

- **带余除法定理**：p, s ∈ P(**F**)，s ≠ 0 ⟹ 存在**唯一** q, r 使 p = sq + r 且 deg r < deg s。
- **次数运算**：deg(pq) = deg p + deg q（零多项式取 deg = −∞ 使公式一致）。

## 案例数据与易错细节

- **证明方法（Axler）**：T(q, r) = sq + r；证 null T = {0}（单射）+ 维数公式（满射），不用长除法构造。
- **易错**：「唯一」依赖 deg r < deg s；放宽则解不唯一。

## 逻辑脉络与关联推演

- 零次次数约定 → 带余除法 → 欧几里得结构 → 零点与因式分解的算法基础。
