# 4.1 复共轭与绝对值

## 核心知识点与关键定义

- **实部与虚部**：z = a + bi（a, b ∈ **R**）时，Re z = a，Im z = b；z = Re z + (Im z)i。
- **复共轭**：z̄ = Re z − (Im z)i。
- **绝对值**：|z| = √((Re z)<sup>2</sup> + (Im z)<sup>2</sup>)。

## 重点结论与公式要点

- z + z̄ = 2 Re z；z − z̄ = 2(Im z)i；zz̄ = |z|<sup>2</sup>。
- w + z 的共轭 = w̄ + z̄；wz 的共轭 = w̄z̄；|wz| = |w||z|。
- |Re z| ≤ |z|，|Im z| ≤ |z|；**三角不等式**：|w + z| ≤ |w| + |z|。

## 案例数据与易错细节

- **案例**：z = 3 + 2i → Re z = 3，Im z = 2，z̄ = 3 − 2i，|z| = √13。
- **易错**：z = z̄ ⟺ z 为实数；|z| 恒为非负实数。

## 逻辑脉络与关联推演

- 为复系数多项式奠定代数工具：共轭、模长、三角不等式 → 后续基本定理与实系数零点分析。
