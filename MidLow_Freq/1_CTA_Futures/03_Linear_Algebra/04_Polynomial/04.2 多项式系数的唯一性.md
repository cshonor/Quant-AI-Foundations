# 4.2 多项式系数的唯一性

## 核心知识点与关键定义

- **多项式**：存在 a<sub>0</sub>, …, a<sub>m</sub> ∈ **F** 使 p(z) = a<sub>0</sub> + a<sub>1</sub>z + … + a<sub>m</sub>z<sup>m</sup> 的函数 p: **F** → **F**。
- **零多项式**：对任意 z ∈ **F** 均有 p(z) = 0 时，所有系数 a<sub>0</sub> = … = a<sub>m</sub> = 0。

## 重点结论与公式要点

- **系数唯一性**：两种系数表示相减得零函数 ⟹ 系数差全为零。
- **次数良定义**：系数唯一 ⟹ 次数（最高次非零指数）唯一。

## 案例数据与易错细节

- **证明思路**：反证 a<sub>m</sub> ≠ 0，取 z 足够大使 |a<sub>m</sub>|z<sup>m</sup> 主导，与 p(z) = 0 矛盾（用三角不等式）。
- **易错**：「函数恒为零 ⟺ 系数全零」在 **R**、**C** 等无限域成立；有限域上非零多项式可能处处为零函数。

## 逻辑脉络与关联推演

- 函数恒等与代数系数一致 → 次数、带余除法才有严格基础。

## 预留拓展空间

- 多项式环 **F**[x] 与多项式函数的区别；特征非零有限域上的差异。
