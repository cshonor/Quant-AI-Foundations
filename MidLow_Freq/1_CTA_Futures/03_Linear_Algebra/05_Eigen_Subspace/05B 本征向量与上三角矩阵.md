# 5.B 本征向量与上三角矩阵

## 核心知识点与关键定义

- **算子多项式 p(T)**：p(z) = a<sub>0</sub> + … + a<sub>m</sub>z<sup>m</sup> ⟹ p(T) = a<sub>0</sub>I + a<sub>1</sub>T + … + a<sub>m</sub>T<sup>m</sup>。
- **M(T)**：基 v<sub>1</sub>, …, v<sub>n</sub> 下，第 k 列为 Tv<sub>k</sub> 的坐标。
- **上三角矩阵**：对角线以下元素全为 0。

## 重点结论与公式要点

- p(T)q(T) = q(T)p(T)（多项式可交换）。
- **复空间本征值存在**：有限维非零**复**向量空间上每个算子必有本征值。
- M(T) 为上三角 ⟺ 对每个 j，Tv<sub>j</sub> ∈ span(v<sub>1</sub>, …, v<sub>j</sub>) ⟺ span(v<sub>1</sub>, …, v<sub>j</sub>) 不变。
- **复空间上三角化**：每个复算子存在某基使 M(T) 上三角。
- T 可逆 ⟺ 上三角矩阵对角元均非 0；本征值 = 对角线元素。

## 案例数据与易错细节

- **证明思路**：取 v ≠ 0，v, Tv, …, T<sup>n</sup>v 共 n+1 个向量线性相关 → p(T)v = 0 → 代数学基本定理分解一次因式 → 某个 (T − λ<sub>j</sub>I) 不单。
- **易错**：「必有本征值」**仅**对复向量空间成立；实空间不一定。

## 逻辑脉络与关联推演

- 算子多项式 + 基本定理 → 复算子有本征值 → 商算子归纳 → 上三角化 → 对角线 = 本征值/可逆判据。
