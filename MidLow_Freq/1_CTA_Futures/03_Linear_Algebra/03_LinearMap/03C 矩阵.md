# 矩阵
## 1. 矩阵与线性映射的一一对应
选定 V 的一组基、W 的一组基之后：
- 任意一个线性映射 T: V -> W，都可以唯一对应一个矩阵。
- 任意一个矩阵，也唯一确定一个线性映射。

## 2. 坐标表示
向量在基下可以写成坐标列向量，此时线性映射作用等价于**矩阵左乘列向量**：
[T(v)]在目标基下的坐标 = M<sub>T</sub> 乘以 [v]在原基下的坐标列向量。

## 3. 矩阵运算的线性意义
1. 矩阵加法 = 线性映射加法
2. 矩阵数乘 = 线性映射数乘
3. 矩阵乘法 = 线性映射复合（先后执行两次变换）

## 4. 核心结论
矩阵只是线性映射在特定坐标系下的数值载体；线性映射是本质，矩阵只是表象。

## 补充梳理（教材要点）

### 核心知识点与关键定义

- **矩阵**：m × n 标量阵列 A<sub>j,k</sub>（j 行 k 列）。
- **M(T)**：V 基 v<sub>1</sub>, …, v<sub>n</sub>，W 基 w<sub>1</sub>, …, w<sub>m</sub>；M(T) 第 k 列是 Tv<sub>k</sub> 在 w 基下的坐标。
- **矩阵乘法**：(AC)<sub>j,k</sub> = Σ<sub>r</sub> A<sub>j,r</sub>C<sub>r,k</sub>；**F**<sup>m,n</sup> 在分量加/数乘下为 mn 维向量空间。

### 重点结论与公式要点

- M(S + T) = M(S) + M(T)；M(λT) = λM(T)；**M(ST) = M(S)M(T)**（矩阵乘法定义由此而来）。
- AC 的第 k 列 = A 乘以 C 的第 k 列。

### 案例数据与易错细节

- **案例**：Dp = p′ 在 P<sub>3</sub>(**R**) → P<sub>2</sub>(**R**) 标准基下为 3×4 次对角矩阵。
- **易错**：无基则矩阵无意义；换基则同一 T 的矩阵不同。
- **易错**：AC ≠ CA，对应 ST ≠ TS。

### 逻辑脉络与关联推演

- 矩阵是线性映射的坐标簿记；为保持同态性而定义矩阵乘法。

### 预留拓展空间

- 初等矩阵 ↔ 基的初等变换；高斯消元法的映射视角。
