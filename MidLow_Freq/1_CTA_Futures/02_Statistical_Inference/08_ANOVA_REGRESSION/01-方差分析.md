# 8.1 方差分析（单因子 ANOVA）

## 一、用途

**方差分析（ANOVA）**：同时比较 **k（k ≥ 3）** 个独立总体均值是否**全部相等**，避免多次两两 **t 检验**导致**第一类错误率膨胀**。

**典型场景**：不同处理、策略、组别在相同指标下的均值差异。

---

## 二、单因子模型

**单因子**：一个分类因素，有 **k** 个水平。

常用模型（第 **i** 个水平下第 **j** 次观测）：

**x<sub>ij</sub> = μ + α<sub>i</sub> + ε<sub>ij</sub>**

| 符号 | 含义 |
| :--- | :--- |
| **μ** | 总均值 |
| **α<sub>i</sub>** | 第 **i** 个水平的效应（常满足 ∑α<sub>i</sub>=0 等约束，以教材为准） |
| **ε<sub>ij</sub>** | 随机误差；经典假设：**独立、正态、同方差** |

---

## 三、平方和分解

将总波动分解为「因子解释部分」与「误差部分」：

**S<sub>T</sub> = S<sub>A</sub> + S<sub>E</sub>**

| 符号 | 名称（常见叫法） |
| :--- | :--- |
| **S<sub>T</sub>** | 总离差平方和 |
| **S<sub>A</sub>** | 因子 **A** 的效应平方和（**组间**） |
| **S<sub>E</sub>** | 误差平方和（**组内**） |

---

## 四、F 检验

构造 **F** 统计量 =（组间均方）/（组内均方），在 H<sub>0</sub>: **α<sub>1</sub> = … = α<sub>k</sub> = 0** 下服从 **F(k−1, n−k)**（**n** 为总样本量，形式以教材推导为准）。

**判定**：**F &gt; F<sub>1−α</sub>(k−1, n−k)** 或 **p &lt; α** → 拒绝 H<sub>0</sub>，认为因子整体显著，**至少两水平**均值有差异。

---

## 五、推广说明

- 各组重复次数**不等**时，公式在 **S<sub>A</sub>、S<sub>E</sub>** 上修正，**F 检验思想不变**。  
- 可进一步估计各水平均值、效应及误差方差 **σ<sup>2</sup>**。

---

## 小结

单因子 ANOVA = **平方和分解 + F 检验**；前提常含**独立、正态、方差齐**（方差齐性可另作检验，见 8.3）。
