# 7.2 正态总体参数的假设检验

## 适用场景

总体服从 **正态分布**时对 **均值 μ**、**方差 σ<sup>2</sup>** 做参数检验；应用最广的基础情形。

---

## 一、单个正态总体 **N(μ, σ<sup>2</sup>)** 的均值检验

检验常见形式：**H<sub>0</sub>: μ = μ<sub>0</sub>**（双侧或单侧视 H<sub>1</sub> 而定）。

### 1. σ<sup>2</sup> **已知** — **Z 检验**

检验统计量：

Z = ( **X̄** − μ<sub>0</sub> ) / ( σ / √n ) ，在 H<sub>0</sub> 成立时近似或精确服从 **N(0, 1)**。

### 2. σ<sup>2</sup> **未知** — **t 检验**

用样本标准差 **S** 代替 σ：

t = ( **X̄** − μ<sub>0</sub> ) / ( S / √n ) ，在 H<sub>0</sub> 成立时服从 **t(n−1)**（自由度 **n−1**）。

---

## 二、与置信区间的对应（双侧）

对均值 μ 的 **1−α** 置信区间与**双侧**检验 **H<sub>0</sub>: μ = μ<sub>0</sub>**：

- 若 **μ<sub>0</sub>** 落在该置信区间内 → **不拒绝** H<sub>0</sub>  
- 若 **μ<sub>0</sub>** 落在区间外 → **拒绝** H<sub>0</sub>  

二者本质是同一线计推断的两种表述。

---

## 三、两个独立正态总体的均值差

设 **X ~ N(μ<sub>1</sub>, σ<sub>1</sub><sup>2</sup>)**，**Y ~ N(μ<sub>2</sub>, σ<sub>2</sub><sup>2</sup>)**，检验 **μ<sub>1</sub> − μ<sub>2</sub>**。

| 情形 | 常用方法 |
| :--- | :--- |
| **两总体方差已知** | **Z 检验**（用样本均值差标准化） |
| **方差未知但 σ<sub>1</sub><sup>2</sup> = σ<sub>2</sub><sup>2</sup>** | **合并方差的 t 检验** |
| **方差未知且不等** | **近似 t 检验**（如 Welch，以教材为准） |

---

## 四、成对数据（配对）的 t 检验

**适用**：同一对象前后对比、配对实验，两组观测**不独立**。

**做法**：作差 **d<sub>i</sub> = x<sub>i1</sub> − x<sub>i2</sub>**（或约定一致的差的方向），对 **{d<sub>i</sub>}** 视为来自某正态总体均值的样本，转为**单样本 t 检验** **H<sub>0</sub>: E(d)=0**（或等于某给定值）。

---

## 五、正态总体方差检验

### 1. 单个总体方差 — **χ<sup>2</sup> 检验**

**H<sub>0</sub>: σ<sup>2</sup> = σ<sub>0</sub><sup>2</sup>** 时常用：

χ<sup>2</sup> = (n−1) S<sup>2</sup> / σ<sub>0</sub><sup>2</sup> ，在 H<sub>0</sub> 成立时服从 **χ<sup>2</sup>(n−1)**。

### 2. 两总体方差比 — **F 检验**

**H<sub>0</sub>: σ<sub>1</sub><sup>2</sup> / σ<sub>2</sub><sup>2</sup> = 1**（或其它比值）时常构造：

F = S<sub>1</sub><sup>2</sup> / S<sub>2</sub><sup>2</sup>（定义方式与分子分母约定以教材为准），服从 **F(n<sub>1</sub>−1, n<sub>2</sub>−1)**。

**用途**：判断波动、风险、稳定性差异是否显著；也是选用「合并 t」或 Welch 的前置参考。

---

## 小结

单总体均值：**σ<sup>2</sup> 已知用 Z，未知用 t**；方差：**χ<sup>2</sup>**；两方差比：**F**；配对用**差值的 t**。
