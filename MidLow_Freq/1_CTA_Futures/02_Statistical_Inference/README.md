# 02 Statistical Inference

> **教材来源**：茆诗松 等《概率论与数理统计教程》（高等教育出版社）Ch 5-8

> 统计推断基础。CTA 信号显著性的数学根基——参数估计、假设检验、回归。

## 内容

| 子目录 | 主题 |
|:---|:---|
| `05_STATISTICS_DISTRIBUTIONS` | 统计分布（χ²/t/F 及应用） |
| `06_PARAMETER_ESTIMATION` | 参数估计（MLE/MoM/区间估计） |
| `07_HYPOTHESIS_TESTING` | 假设检验（Z/t/χ²/F 检验） |
| `08_ANOVA_REGRESSION` | 方差分析与回归 |

## CTA 侧重

- **假设检验**是信号有效性验证的核心工具
- **MLE** 是 GARCH/ARMA 参数估计的标准方法
- **回归**对应因子线性模型，ANOVA 对应因子显著性
