# §4.4 中心极限定理（CLT）

**适当标准化后的和或均值**，在 n 很大时**依分布收敛**到**标准正态**。公式用 **HTML 上下标**（见仓库根目录 [`书写约定-上下标与公式.md`](../../书写约定-上下标与公式.md)）。

---

## 1. 林德伯格–列维（Lindeberg–Lévy）CLT

### 适用条件
- X<sub>1</sub>, …, X<sub>n</sub> **i.i.d.**  
- E(X<sub>i</sub>) = μ，D(X<sub>i</sub>) = σ<sup>2</sup> **存在**且 **σ<sup>2</sup> &gt; 0**

### 定理结论
记 S<sub>n</sub> = X<sub>1</sub>+⋯+X<sub>n</sub>，则

( S<sub>n</sub> − nμ ) / ( σ√n ) **依分布收敛于** N(0, 1)（n → ∞）。

**等价**（样本均值 X̄<sub>n</sub> = S<sub>n</sub>/n）：

( X̄<sub>n</sub> − μ ) / ( σ / √n ) **依分布收敛于** N(0, 1)。

### 白话
原分布不必是正态；只要 i.i.d. 且方差有限为正，大 n 下标准化后的**和或均值**的分布形状接近正态。

---

## 2. 棣莫弗–拉普拉斯（De Moivre–Laplace）CLT

### 适用条件
Y<sub>n</sub> ~ B(n, p)，即 n 次独立伯努利成功次数。

### 定理结论

( Y<sub>n</sub> − np ) / √( n p(1−p) ) **依分布收敛于** N(0, 1)。

### 常用经验判定
**np ≥ 5** 且 **n(1−p) ≥ 5** 时，正态近似常较可用（经验法则）。

### 与林德伯格–列维的关系
令 X<sub>i</sub> 为第 i 次 0-1 成功指示，则 X<sub>i</sub> i.i.d.，Y<sub>n</sub> = X<sub>1</sub>+⋯+X<sub>n</sub>，故本定理为上一节的**特例**。

---

## 核心对比表

| 定理 | 分布要求 | 矩条件 | 核心用途 |
| :--- | :--- | :--- | :--- |
| **林德伯格–列维** | i.i.d. | E、D 存在且 D&gt;0 | 标准化 **和/均值** → **N(0,1)** |
| **棣莫弗–拉普拉斯** | 二项 B(n,p) | 实用上 **np、n(1−p)** 较大 | **二项**概率用**正态近似** |

---

## 大数定律 vs 中心极限定理

- **弱大数**：样本均值 **依概率** 贴近 μ（**值**稳定）。  
- **CLT**：标准化和/均值 **依分布** 贴近正态（**形**稳定）。

---

## 应用要点

1. 判型：i.i.d. **部分和** 或 **二项 Y<sub>n</sub>**。  
2. 写 **期望、方差**，套 **(和 − 期望) / 标准差**，极限为 N(0,1)。  
3. 有限 n 算概率时，视教材使用 **0.5 连续性修正**。
