# 8.4 一元线性回归

## 一、两类关系

- **函数关系**：变量间严格确定的公式关系。  
- **统计相关**：存在趋势但含随机扰动；**回归分析**研究后者。

---

## 二、模型

**Y = a + b X + ε**

| 符号 | 含义 |
| :--- | :--- |
| **X** | 自变量（解释变量） |
| **Y** | 因变量（被解释变量） |
| **a** | 截距 |
| **b** | 斜率：X 每增 1 单位，Y **均值**的平均变化量 |
| **ε** | 随机误差；经典假设：**零均值、同方差、独立、正态**（用于推断） |

---

## 三、最小二乘估计（OLS）

最小化 **残差平方和 ∑(y<sub>i</sub> − â − b̂ x<sub>i</sub>)<sup>2</sup>**，得到唯一 **â、b̂**；是线性模型与多因子模型的基础。

---

## 四、显著性与拟合优度

| 内容 | 作用 |
| :--- | :--- |
| **b 的 t 检验** | 检验 X 对 Y 是否有显著线性贡献 |
| **方程的 F 检验** | 检验回归方程整体是否显著 |
| **R<sup>2</sup>** | 样本决定系数，**0～1**，越大表示线性拟合解释的变异比例越高（注意过拟合与相关≠因果） |

---

## 五、预测

- **E(Y | X = x<sub>0</sub>)** 的**置信区间**（均值响应）  
- **单个 Y** 在 **X = x<sub>0</sub>** 时的**预测区间**（通常更宽）  

---

## 六、可线性化的非线性回归

对 **Y = f(X)** 为指数、对数、幂函数等时，常通过 **ln**、**倒数**等变换化为对参数的线性模型，再用 **OLS**，最后注意**还原与误差结构是否仍合理**。

---

## 小结

一元线性回归 = **OLS + t/F + R<sup>2</sup> + 区间预测**；推广到多元即 **CAPM、多因子**等方向的起点。
