# 第 2 章 · 认识你的数据！

## 本章讲什么

数据从哪来、样本与总体的关系、描述性统计指标怎么选。本章是全书的地基：**一切推断的前提是知道数据的来路**。

## 要点

### 数据本质

- 数据只是**事件的快照**（类比家庭照片），**不等于完整真相**。
- 要追问数据来源，不能盲目信奉"数据驱动"，提倡**"分析驱动"**。

### 四大数据来源

1. **传感器采集**
2. **软件行为日志**
3. **人工标注录入**
4. **模拟生成的合成数据**

### 样本与总体

| 概念 | 定义 |
| :--- | :--- |
| **总体** | 想要研究的全部对象 |
| **样本** | 从总体抽取的子集，用来**推断**总体 |

实操建议：

- **默认把手上所有数据当作样本**（而非总体）；
- 警惕**抽样偏差**、**自我选择偏差**。

### 数字类型

自然数 → 整数 → 实数（有理数、无理数）；计算机**浮点数存在近似误差**。

### 描述性统计指标

**集中趋势**：

- **均值**：易受异常值影响；
- **中位数**：抗异常值，适合偏斜数据；
- **众数**：出现频次最高的值。

**分位数**：

- 四分位数、四分位距 **IQR**——刻画中间 50% 数据的分布。

**离散程度**：

- **方差、标准差**；
- 样本方差要做**贝塞尔校正**（分母 n−1，写作 n<sub>-1</sub> 或用 `<sub>` 排版为 n − 1），否则会系统性低估总体方差。

> **选型口诀**：偏态分布优先使用**中位数 + 四分位距**，而非均值 + 标准差。

### 真实案例：NOAA 龙卷风数据集

- 龙卷风宽度呈**右偏分布**，均值**远大于**中位数；
- 龙卷风等级（EF 强度）越高，其中位宽度越大。

## 代码示例

```python
import numpy as np
import pandas as pd

# 贝塞尔校正：样本方差分母为 n-1（ddof=1）
x = pd.Series([2.1, 3.5, 2.8, 4.0, 3.9, 15.0])  # 15.0 是异常值
print(x.mean(), x.median())            # 均值被拉高 vs 中位数稳健
print(x.var(ddof=1))                   # 样本方差（贝塞尔校正）
print(x.quantile([0.25, 0.5, 0.75]))   # 四分位数
print(x.quantile(0.75) - x.quantile(0.25))  # IQR
```
