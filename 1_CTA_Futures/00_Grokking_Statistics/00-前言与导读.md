# 前言 · 致谢 · 本书导读

> Thomas Nield《Grokking Statistics》前言与导读部分笔记。

## 本章讲什么

作者自述学习动机、本书定位与使用方法，以及配套代码资源说明。

## 要点

### 写作动机

- 作者过往学习统计时体验糟糕（传统教材重推导记忆、轻直觉）。
- 受 AI 与数据科学热潮启发写成本书，希望传授**统计学底层核心概念**，而不是堆砌代码。

### 学习建议

1. **优先吃透基础大概念**，再按需拓展细分主题。
2. **前 5 章建议顺序阅读**——概念层层递进（描述统计 → 概率 → 分布 → 样本量 → 假设检验）。
3. 第 9、10 章（统计陷阱、职场生存指南）可以**随时跳转**。

### 读者适用

分析师、工程师、科研人员、管理者——所有日常接触数据、报表、SQL 的人。

### 配套资源

- 全部示例 Python 代码托管在线。
- 技术栈：`numpy`、`pandas`、`matplotlib`、`scipy`。
- 不需要高阶 Python 能力，掌握基础语法即可跟上。
