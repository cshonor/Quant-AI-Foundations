# Route 3: AI Agent

> 线性代数 + 凸优化 + 机器学习 + 实分析（可选）。

## 学习顺序

| 序号 | 文件夹 | 内容 | 重点 |
|:---:|:---|:---|:---|
| 1 | `01_Alg` | 线性代数 | 向量表示、相似度、图搜索与规划 |

## 学习要点

- **Alg 侧重向量空间和线性映射**：embedding 的数学本质就是向量空间映射，相似度计算（余弦、内积）是检索的基础。
- **CO 侧重梯度下降和正则化**：训练 LLM 的核心是优化器（AdamW、学习率调度），正则化防止过拟合。
- **ML 全部章节都相关**：从线性回归到 Gradient Boosting 都是基础，重点关注 `10_Neural_Networks` 和 `13_Real_World_Data_Engineering_and_ML_Practice`。
- **RFA 可选**：想深入理解函数逼近、核方法的理论基础时再学。

## 与其他路线的关系

- `01_Alg`、`02_CO`、`03_ML` 与 Route 2 (Equity MultiFactor) 共享。
- `04_RFA` 与 Route 1 (CTA) 共享，但侧重不同——本路线侧重函数逼近，CTA 路线侧重测度论。
