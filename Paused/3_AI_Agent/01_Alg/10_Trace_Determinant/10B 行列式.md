# 10.B 行列式

## 核心知识点与关键定义

- **算子的行列式 det T**：
  - **C** 上：按重数重复的本征值之积；
  - **R** 上：T<sub>C</sub> 的本征值（按重数）之积。
- **排列符号**：(1, …, n) 的排列；逆序对数为偶 ⟹ +1，奇 ⟹ −1；交换两元 ⟹ 符号 × (−1)。
- **矩阵行列式**：det A = Σ sign(m<sub>1</sub>, …, m<sub>n</sub>) A<sub>m<sub>1</sub>,1</sub>⋯A<sub>m<sub>n</sub>,n</sub>。
- **长方体体积**（**R**<sup>n</sup>）：各边长之积。
- **导数 σ′(x)**：可微映射在一点处的线性近似；矩阵 = 雅可比矩阵。

## 重点结论与公式要点

- T 可逆 ⟺ det T ≠ 0。
- 特征多项式 = det(zI − T)；det T = (−1)<sup>n</sup> × 特征多项式常数项。
- 特征多项式：z<sup>n</sup> − (trace T)z<sup>n−1</sup> + … + (−1)<sup>n</sup>(det T)。
- **矩阵 det 三性质**：交换两列 ⟹ ×(−1)；两列相同 ⟹ 0；对每列线性。
- det(AB) = (det A)(det B)；det(ST) = (det S)(det T)；det T = det M(T)。
- 极分解：|det S| = 1（S 等距）；|det T| = det √(T\*T)。
- **体积**：volume T(Ω) = |det T| · volume Ω。
- **换元积分**：∫<sub>σ(Ω)</sub> f(y) dy = ∫<sub>Ω</sub> f(σ(x)) |det σ′(x)| dx。

## 案例数据与易错细节

- **案例**：极坐标 σ(r, θ) = (r cos θ, r sin θ)，det σ′ = r；球坐标 det = ρ<sup>2</sup> sin φ。
- **易错**：排列定义共 n! 项，高维**不用于**手算；实际上三角化（上三角 det = 对角线之积）。
- **易错**：det 的符号反映「定向」/ 镜像次数（奇次负、偶次正）。

## 逻辑脉络与关联推演

- 本征值之积定义 det → 排列定义矩阵 det → det(AB)=det(A)det(B) → 基无关 → 极分解 ⟹ |det| = 体积缩放 → 雅可比换元。

## 预留拓展空间

- LU 分解 O(n<sup>3</sup>) 求 det；微分形式与外代数解释「交换列变号」。
