# 7.A 自伴算子与正规算子

## 核心知识点与关键定义

- **伴随 T\***：T ∈ L(V, W)，唯一 T\* : W → V 满足 ⟨Tv, w⟩ = ⟨v, T\*w⟩。
- **共轭转置**：矩阵先转置再逐元取复共轭。
- **自伴算子**：T ∈ L(V)，T = T\*（即 ⟨Tv, w⟩ = ⟨v, Tw⟩）。
- **正规算子**：TT\* = T\*T。

## 重点结论与公式要点

- (S + T)\* = S\* + T\*；(λT)\* = λ̄T\*；(T\*)\* = T；I\* = I；(ST)\* = T\*S\*。
- null T\* = (range T)<sup>⊥</sup>；range T\* = (null T)<sup>⊥</sup>；null T = (range T\*)<sup>⊥</sup>；range T = (null T\*)<sup>⊥</sup>。
- 规范正交基下：**M(T\*) = M(T) 的共轭转置**。
- 自伴算子本征值均为**实数**。
- T 正规 ⟺ 对所有 v，‖Tv‖ = ‖T\*v‖。
- T 正规 ⟹ T 与 T\* 有相同本征向量；不同本征值的本征向量彼此正交。

## 案例数据与易错细节

- **案例**：T(x<sub>1</sub>, x<sub>2</sub>, x<sub>3</sub>) = (x<sub>2</sub> + 3x<sub>3</sub>, 2x<sub>1</sub>) 的伴随 T\*(y<sub>1</sub>, y<sub>2</sub>) = (2y<sub>2</sub>, y<sub>1</sub>, 3y<sub>1</sub>)。
- **易错**：M(T\*) = M(T)<sup>t</sup>̄ **仅**在规范正交基下成立。
- **易错**：自伴 ⟹ 正规，反之不成立（如 **R**<sup>2</sup> 旋转算子）。

## 逻辑脉络与关联推演

- 伴随 = 内积空间的「复共轭」抽象 → 自伴（z = z̄）→ 正规（更一般的交换性）→ 谱定理的代数基础。

## 预留拓展空间

- 非规范正交基下求 T\* 矩阵；量子力学中 Hermitian 算子 = 可观测量。
