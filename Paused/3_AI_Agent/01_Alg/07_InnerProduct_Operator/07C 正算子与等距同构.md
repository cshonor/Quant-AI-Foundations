# 7.C 正算子与等距同构

## 核心知识点与关键定义

- **正算子**：T 自伴且对所有 v，⟨Tv, v⟩ ≥ 0。
- **平方根**：R<sup>2</sup> = T 时 R 为 T 的平方根。
- **等距同构**：对所有 v，‖Sv‖ = ‖v‖（保范数）。

## 重点结论与公式要点

- T 正 ⟺ T 自伴且本征值 ≥ 0 ⟺ T 有正平方根 ⟺ T 有自伴平方根 ⟺ ∃R 使 T = R\*R。
- 正算子的**正平方根** √T **唯一**。
- S 等距 ⟺ ⟨Su, Sv⟩ = ⟨u, v⟩ ⟺ S\*S = I ⟺ SS\* = I ⟺ S\* 等距 ⟺ S 将规范正交基映为规范正交基。
- **C** 上等距 ⟺ 有规范正交本征基且 |本征值| = 1。

## 案例数据与易错细节

- **案例**：正交投影 P<sub>U</sub> 是正算子（⟨P<sub>U</sub>v, v⟩ = ‖P<sub>U</sub>v‖<sup>2</sup> ≥ 0）。
- **易错**：正算子类比非负实数 [0, ∞)；文献中亦称半正定。
- **易错**：**R** 上等距（正交算子）可无实本征值（旋转），故不一定实对角化。

## 逻辑脉络与关联推演

- 自伴 ↔ 实数 → 正算子 ↔ 非负实数 → 唯一正平方根；等距 ↔ 单位圆 |z| = 1 → S\*S = I。
