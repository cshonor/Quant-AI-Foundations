# 8.C 特征多项式与极小多项式

## 核心知识点与关键定义

- **特征多项式**：q(z) = (z − λ<sub>1</sub>)<sup>d<sub>1</sup></sup>⋯(z − λ<sub>m</sub>)<sup>d<sub>m</sup></sup>，d<sub>j</sub> = dim G(λ<sub>j</sub>, T)。
- **首一多项式**：最高次项系数为 1。
- **极小多项式**：使 p(T) = 0 的**次数最小**的**首一**多项式。

## 重点结论与公式要点

- deg q = dim V；q 的零点（含重数）= T 的全部本征值。
- **凯莱-哈密顿定理**：q(T) = 0。
- q(T) = 0 ⟺ q 是极小多项式的倍式。
- 特征多项式是极小多项式的倍式；两者根集相同，极小多项式中各根重数可能更低。

## 案例数据与易错细节

- **案例**：本征值 6（重 2）、7（重 1）→ q = (z − 6)<sup>2</sup>(z − 7)；极小多项式可能是 (z − 6)(z − 7) 或 (z − 6)<sup>2</sup>(z − 7)，需检验 (T − 6I)(T − 7I) 是否为零。
- **易错**：Axler 不用 det(zI − T) 定义特征多项式，而从重数构造，使凯莱-哈密顿证明更短。

## 逻辑脉络与关联推演

- 重数构造 q → 分解定理证 q(T) = 0 → 极小多项式为「最简零化方程」的生成元。

## 预留拓展空间

- 极小多项式在可控性/可观测性中的应用；Krylov 子空间算法。
