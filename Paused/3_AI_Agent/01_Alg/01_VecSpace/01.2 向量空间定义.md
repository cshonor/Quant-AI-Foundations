# 1.B 向量空间定义

## 一、向量空间（线性空间）定义

设 **F** 为**标量域**（本书只考虑 **R** 或 **C**），V 为非空集合，定义两种运算：

- **加法**：V × V → V，(u, v) ↦ u + v  
- **标量乘法**：**F** × V → V，(λ, v) ↦ λv  

对 ∀ u, v, w ∈ V，∀ λ, μ ∈ **F**，满足**八条公理**：

| # | 名称 | 公式 |
| :---: | :--- | :--- |
| 1 | 交换律 | u + v = v + u |
| 2 | 结合律 | (u + v) + w = u + (v + w) |
| 3 | 加法单位元 | ∃ 零向量 **0** ∈ V，v + **0** = v |
| 4 | 加法逆元 | ∀ v，∃ −v ∈ V，v + (−v) = **0** |
| 5 | 数乘结合律 | λ(μv) = (λμ)v |
| 6 | 数乘单位元 | 1 · v = v（1 是 **F** 的乘法单位元） |
| 7 | 分配律 1（标量和） | (λ + μ)v = λv + μv |
| 8 | 分配律 2（向量和） | λ(u + v) = λu + λv |

则称 **V 是 F 上的向量空间**；V 中元素叫**向量（或点）**。

- **实向量空间**：**F** = **R**  
- **复向量空间**：**F** = **C**

---

## 二、基本性质（由公理推出）

### 1. 唯一性

- **零向量唯一**：若 **0**<sub>1</sub>、**0**<sub>2</sub> 都是零向量，则 **0**<sub>1</sub> = **0**<sub>1</sub> + **0**<sub>2</sub> = **0**<sub>2</sub>。  
- **加法逆元唯一**：每个 v 的 −v 唯一。

### 2. 三个常用等式（必考证明）

**① 0v = 0**（左 0 是标量，右 0 是零向量）

```
0v = (0 + 0)v = 0v + 0v
两边加 0v 的逆元 → 0 = 0v
```

**② λ · 0 = 0**

```
λ0 = λ(0 + 0) = λ0 + λ0
两边加逆元 → λ0 = 0
```

**③ (−1)v = −v**

```
v + (−1)v = 1v + (−1)v = (1 − 1)v = 0v = 0
由逆元唯一 → (−1)v = −v
```

## 三、典型向量空间

| 空间 | 定义 | 维数 |
| :--- | :--- | :--- |
| **F**<sup>n</sup> | {(x<sub>1</sub>, …, x<sub>n</sub>) \| x<sub>i</sub> ∈ **F**} | n |
| **F**<sup>∞</sup> | 无穷序列 (x<sub>1</sub>, x<sub>2</sub>, …) | 无穷维 |
| **F**<sup>S</sup> | 函数 f : S → **F**；(f + g)(x) = f(x) + g(x)；(λf)(x) = λf(x) | 一般无穷维 |
| **P**(**F**) | 系数在 **F** 上的多项式全体 | 无穷维 |

特例：S = {1, …, n} 时 **F**<sup>S</sup> = **F**<sup>n</sup>。

---

## 四、易错细节（高频）

1. **0v = 0 中两个 0 不同**：左 = 标量 0 ∈ **F**；右 = 零向量 **0** ∈ V。  
2. **证明只能用八条公理**，不能用坐标或几何直觉偷换。  
3. **向量空间必含零向量**；验证子集时通常先确认 **0** ∈ U。

### 标量世界 vs 向量世界

| 对象 | 所属 | 作用 |
| :--- | :--- | :--- |
| 0, 1, λ, μ | **F**（标量） | 数乘系数 |
| **0**, v, −v | V（向量） | 加法运算对象 |

不同 V 中「零向量」外形不同：**R**<sup>3</sup> 中是 (0, 0, 0)；矩阵空间是零矩阵；函数空间是零函数。

---

## 五、逻辑脉络

- **1.A（F**<sup>n</sup>**）**：具体坐标模型。  
- **1.B（向量空间）**：公理化抽象——只保留加法、数乘与八条公理。  
- 由公理统一推出唯一性、0v = 0 等共有性质。  
- 完成：**从「数组」到「抽象结构」**的跨越。

---

## 六、拓展

- **非向量空间反例**：**R**<sup>2</sup> 上 (a, b) + (c, d) = (a + c, 0)（破坏公理）；**R**<sup>+</sup> 在普通加法下无零元。  
- **代数结构**：向量空间 = **域上的模**；加法构成**交换群**。

---

## 七、实变/泛函对照（拓展）

| 空间类型 | 结构 | 公理管什么 | 典型用途 |
| :--- | :--- | :--- | :--- |
| 度量空间 (X, d) | 集合 + 距离 | 远近、收敛 | 极限、连续 |
| 可测空间 (X, σ-代数) | 集合 + σ-代数 | 可测集 | 积分、概率 |
| 向量空间 (V, +, ·) | 集合 + 线性运算 | 线性结构 | 基、维数、线性映射 |

泛函分析 ≈ 线性空间理论 + 分析结构（极限、拓扑、完备性）。

---

## 一句话总结

向量空间的本质是：**在集合 V 上，加法与数乘满足八条公理**；函数、序列、多项式与 **F**<sup>n</sup> 数组一样，都可能是「向量」。
