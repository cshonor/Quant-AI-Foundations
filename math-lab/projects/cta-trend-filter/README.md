# 项目：CTA 趋势策略作为贯穿案例

> 这个目录不是「一本数学书的某一章」，而是**一个贯穿案例**：
> 用你贴的那段 CTA 代码（均线交叉 + ADX 过滤 + ATR 止损）把数学拆开来看。
> 每个 `.py` 都是独立可跑的小节，被 `run_all.py` 收集进站点。

## 目录

| 文件 | 数学主题 | 判决的命题 |
| :--- | :--- | :--- |
| `10.1-图会说谎` | 坐标 / 尺度 / 采样密度 | 线性轴与对数轴的回撤排序不一致（ρ=0.88）；降采样低估回撤（日 53.0% → 周 51.8% → 月 49.4%）；超 Nyquist 采样量到 91 天的假周期（真值 7 天） |
| `10.2-递推平滑` | 一阶线性递推 | Wilder/EMA/SMA 是同一个递推；初值遗忘率 = ln(1−1/N)（半衰期 9.4 根）；相位滞后 SMA 6.5 根 vs EMA 13 根（正好 2 倍）；降噪能力反过来（EMA 方差是 SMA 的 2 倍） |
| `10.3-ADX` | 比值 / 量纲 / 不连续决策 | 递推 ≡ 几何加权和（1e-16）；横盘时 ±DI 都是 0 不是 50/50，ADX 为 NaN；两种量纲口径的差异只是初值差（前 100 根 4.7e-4 → 尾部 5.6e-16）；ADX 良态但阈值决策是阶跃 |
| `10.4-资金曲线` | 连乘 / AM–GM / 估计量 | 波动拖累 = σ²/2（实测 301.6 vs 303.5 bp/日）；打乱顺序终值恒定但回撤 28%–77%；回撤 76.6% 需涨 328%；Sharpe 标准误理论 0.72 / bootstrap 0.53 |
| `10.5-过滤器` | 布尔代数 / 集合划分 | 容斥恒等式精确成立（22 = 14 + 8）；原写法吞掉 5 次反手信号、最长持仓 127 → 183 根；改用「平仓用原始信号」后被吞次数归零 |
| `strategy.py` | 综合 | 修好的完整策略（含 ATR 百分比止损、盘中触发、下根开盘成交） |
| `_indicators.py` | — | 指标与回测工具（无 vectorbt / TA-Lib 依赖，可照抄到 Go/C++） |

## 数据

`data/btc_usdt_1d.csv`：BTCUSDT 日线，2000 根，来自币安公开接口（免密钥）。
最后一根未闭合的 K 线已被剔除。重新抓取：

```bash
python data/fetch_btc.py 2000
```

## 跑法

```bash

PYTHONDONTWRITEBYTECODE=1 <mathlab-python> run_all.py         # 全部

```

## 对原始代码的三处修改（及理由）

1. **`vbt.ADX` 不存在** → 用 `_indicators.wilder_adx` 自己实现（Wilder 口径，与 TA-Lib 逐点对齐到 1e-14）。
2. **`sl_stop` 是百分比不是金额** → 传 `(k·ATR)/close`。原文的几百/几千当百分比用，等于「回撤几万 % 才止损」，实测一次都没触发。
3. **平仓不能用过滤后的信号** → `exits` 改用未过滤的反向信号。原写法把 `entries_short`（已 `& adx>=20`）接到 `exits` 上，ADX<20 那天的死叉既不反手也不平仓，持仓被锁死。

## 诚实的结论

修好之后仍然跑输买入持有（3 年样本：策略 −19.2% vs 持有 +220.1%，且加了 ATR 止损比不加更差）。
20/60 日均线三年只产生 22 次交叉，过滤后 14 次 —— **这个样本量只能用来验证「代码有没有照你的想法执行」，不能用来判断策略好坏**。
这也是为什么本目录的价值在 10.1–10.5 的数学命题，而不在 `strategy.py` 的收益率。
